# 产品愿景

> 品牌与口号由现有产品确认。未标注 `[反推]` 的段落为产品意图。

## 品牌定位

- **名称**：TMD（TABLETOP MASTER DESIGN）/ 桌游大师
- **口号**：一站式桌游制作测试网站
- **承诺**：永久免费
- **作者**：张苏杭

## 目标用户

- 桌游设计师、模组作者、卡牌与桌游爱好者
- 需要在浏览器或 **桌面窗口** 完成桌游几个制作维度（卡牌、板件、包装盒、说明书），并测玩法、打样、出产品静帧 / 宣传镜头序列的用户
- 不需要专业 DTP / 三维包装软件即可起步的轻量创作者

`[反推]` 当前实现仍以卡牌蓝图与数据集为主，包装盒与说明书尚未落地。

## 核心场景

工作室一级入口是 **桌游创作**（不再叫「卡牌创作」）。一个项目覆盖桌游制作的几个维度：

1. **卡牌** — 蓝图排版 + 数据集批量填充。可设纸厚与卡芯（产品渲染用）。详见 [pieces.md](./features/pieces.md)。
2. **板件** — 上传一张图（如秘宝.png），按透明通道扣形并给厚度；产品渲染里可取用。详见 [boards.md](./features/boards.md)。
3. **包装盒** — 从默认方盒起步，调尺寸，导入**一张**贴图（原始尺寸 / 撑满 / 平铺），棱可倒角，在 UV 编辑器里像 Maya 那样放置/缩放各面，再做产品渲染。详见 [packaging.md](./features/packaging.md)。
4. **说明书** — 规则书 / 说明书的编写与排版。详见 [rulebook.md](./features/rulebook.md)。

然后：

5. **产品渲染** — 先选场景块再进编辑；透视或等距；用控制杆摆卡/板/盒；可套布局模版；打灯光、描边、滤镜，导出**静帧**产品图；场景不够用时可 **导出 FBX** 去 Maya 接着渲。详见 [product-render.md](./features/product-render.md)。
6. **影棚** — 独立于静帧：选模版、填演员、拧秒数；可把产品场景当布景；写出 PNG 序列给剪辑做宣传片；当前帧也可导出 FBX。详见 [studio.md](./features/studio.md)。须在 [桌面客户端](./features/desktop-app.md) 里渲序列。
7. **测试与输出** — 虚拟牌桌联机试玩，或按打印拼版 / TTS 贴图 / 单图导出 PDF、PNG、JPG。

附加场景：

- 从模板库（扑克、三国杀、万智牌等）快速起步卡牌
- 在市场中浏览/订阅他人项目
- 局域网或广域网联机对战

## 产品边界（不做的事）

- 不是通用矢量/位图编辑器（卡牌/板件聚焦成品尺寸与变量化排版）
- 不是完整三维 DCC（包装盒只做方盒参数、贴图 UV；产品渲染只做静帧摆放，可把场景导出 FBX 给 Maya；影棚只做模版镜头，不做 Graph Editor / 骨骼 / 剪辑时间轴）
- 不是完整规则引擎（对战模式提供牌桌与同步，不内置复杂游戏规则）
- 市场/论坛为轻量社区功能，非完整社交平台
- 不强制账号登录（本地项目 + 可选联机昵称）

`[反推]` 当前版本未覆盖包装盒与说明书。

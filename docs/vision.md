# 产品愿景

> 品牌与口号由现有产品确认。未标注 `[反推]` 的段落为产品意图。

## 品牌定位

- **名称**：TMD（TABLETOP MASTER DESIGN）/ 桌游大师
- **口号**：一站式桌游制作测试网站
- **承诺**：永久免费
- **作者**：张苏杭

## 目标用户

- 桌游设计师、模组作者、卡牌与桌游爱好者
- 需要在浏览器或本地完成**桌游几个制作维度**（卡牌/板件、包装盒、说明书），并测玩法、打样的用户
- 不需要专业 DTP / 三维包装软件即可起步的轻量创作者

`[反推]` 当前实现仍以卡牌蓝图与数据集为主，包装盒与说明书尚未落地。

## 核心场景

工作室一级入口是 **桌游创作**（不再叫「卡牌创作」）。一个项目覆盖桌游制作的几个维度：

1. **卡牌 / 板件** — 蓝图排版 + 数据集批量填充。卡牌无厚度；板件可设厚度。详见 [pieces.md](./features/pieces.md)。
2. **包装盒** — 从默认方盒起步，调尺寸，导入**一张**贴图，在 UV 编辑器里像 Maya 那样放置/缩放各面，再做产品渲染。详见 [packaging.md](./features/packaging.md)。
3. **说明书** — 规则书 / 说明书的编写与排版。详见 [rulebook.md](./features/rulebook.md)。

然后：

4. **测试与输出** — 虚拟牌桌联机试玩，或导出 PDF/PNG 打印。

附加场景：

- 从模板库（扑克、三国杀、万智牌等）快速起步卡牌/板件
- 在市场中浏览/订阅他人项目
- 局域网或广域网联机对战

## 产品边界（不做的事）

- 不是通用矢量/位图编辑器（卡牌/板件聚焦成品尺寸与变量化排版）
- 不是完整三维 DCC（包装盒只做方盒参数、贴图 UV、产品渲染，不做自由建模）
- 不是完整规则引擎（对战模式提供牌桌与同步，不内置复杂游戏规则）
- 市场/论坛为轻量社区功能，非完整社交平台
- 不强制账号登录（本地项目 + 可选联机昵称）

`[反推]` 当前版本未覆盖包装盒与说明书。

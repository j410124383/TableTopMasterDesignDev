# 产品渲染

> 把项目里的卡牌、板件、包装盒摆进同一套三维产品视口，出产品图。  
> **入口与蓝图 / 包装盒一致**：先看场景预览块，再点进内部编辑。  
> **视口、灯光、网格/轴、导出路径延续包装盒渲染**（见 [packaging.md](./packaging.md)），之后两入口合并为同一模式。

## 用户故事

- 作为设计者，我希望先看到有哪些产品场景，再点进某一个去摆。
- 作为设计者，我希望从左侧产品栏预览卡牌集、单张卡、板件和包装盒，再放进场景里摆。
- 作为设计者，我希望像主流 3D 软件一样：透视或等距、物件上有控制杆，拖杆或改数值都能变换。
- 作为设计者，我希望卡和卡牌集默认趴在桌上，圆角、纸厚、白芯侧边跟实物一样；卡牌集按张数有真实厚度差。
- 作为设计者，我希望拖进场景的卡牌集头尾方向是对的，并且能限定用其中几张、换成错落 / 一字 / 扇形，而不是永远一个实心方块。
- 作为设计者，我希望能套用「盒在中间、卡扇开 / 一字排开」这类布局模版，再填自己的盒和卡。
- 作为设计者，我希望成品图能描边、套滤镜，而不是只有素模。
- 作为设计者，我希望视口里直接看到即将导出的画幅，并能平移镜头构图。
- 作为设计者，我希望渲染页有大纲，能看到场景里有哪些物体；能创建 Maya 式摄像机，把视口贴合到那台机上再出图。
- 作为设计者，我希望视口里糊一点没关系，但点「渲染」出的成品图是最高可用质量；卡面、板件贴图不能比盒子糊。
- 作为设计者，我希望把当前场景导出成 Maya 能打开的模型（网格 + UV + 漫反射贴图），影棚不够用时拿到 Maya 里接着渲。

宣传镜头 / 转台 / 开盒视频不在本页做，见 [studio.md](./studio.md)。

## 范围

**做**：场景库 + 场景编辑；大纲视窗；左侧产品栏（含创建摄像机）；Maya 式场景摄像机（视口/出图跟当前看穿的那台）；透视/等距；变换控制杆；多物件摆放；内置布局模版；卡/集圆角挤出与纸厚；与包装盒相同的灯光/辅助线；轮廓描边；少量成品滤镜；导出 PNG 到 `渲染图/`；**导出模型（ASCII FBX+贴图）到 `导出模型/`**；打开本机渲染文件夹；渲染模式中键平移镜头。

**不做**：完整 DCC（骨骼、粒子、布料、Graph Editor）、自定义模版编辑器、影视级合成软件、按像素画滤镜节点图、物理正确 GI、纸张弯曲与物理碰撞。牌组形态仍是一块挤出网格；错落 / 一字 / 扇形才逐张薄片（有张数上限）。**本页不出序列帧、不编码 mp4**。宣传镜头见 [studio.md](./studio.md)。

## 界面与交互

### 入口

工作区项目级入口 **产品渲染**（与打印、舞台同级），路由建议 `/project/shot`。

包装盒编辑器里的「渲染」步骤**暂时保留**（只渲当前那一只盒）。产品渲染页可以放入多只盒 + 卡 + 板。实现上共用视口组件；后续再收成一个入口。

### 库：场景预览块 → 再进入编辑

进入「产品渲染」后，**先进入场景库**（对标蓝图库、包装库），不要直接丢进某一个场景的编辑器。

- 每个 `ProductShot` 一张 **预览块**（**低质量三维场景缩略** + 名称）。缩略要能看出场景里大概摆了什么，禁止只有「N 件 / 空场景」两行字。未完成贴图时可以用占位体，但不能整块空白。
- 点击预览块 → 进入该场景的内部编辑（产品栏 + 视口 + 属性）
- 顶栏或库内：**新建场景**（空场景，或先选一个布局模版再建）
- 右键：重命名、复制、删除（可删到 0 个，回到空状态）
- 编辑器内提供 **返回库**

空项目：库为空态 + 「新建场景」，**不要**在进本页时偷偷自动建「产品图 1」并跳进编辑。

### 编辑页布局

页头 **尽量矮**：只留场景名、返回库、导出等主操作。教学说明（怎么拖、控制杆、模版）放标题旁 **问号图标** 弹出，见 [ui-consistency.md](./ui-consistency.md)。禁止用大段 `muted` 副标题占掉视口。

| 区域 | 内容 |
|------|------|
| 左栏 **大纲** | 与创建 **左右并列**。当前场景里的物体（摄像机、盒、卡、集、板）。点选与视口同步 |
| 左栏 **创建** | 大纲旁边。标题「创建」，**下面**才是产品栏：预览并可拖入 / 点选加入场景。**Tab + 数字翻页**。包装盒后面是 **摄像机** |
| 中央 | 三维产品视口。左上角（或画幅附近）**明确写当前看穿的摄像机名称**，例如「看穿：persp」 |
| 右栏 | **图标 TabGroup**（见下），不要再把场景/模版/机位/灯/滤镜/物件搓成一长列 |

左右栏宽度 **可拖拽边框** 调整；大纲与创建之间也可拖分割，见 [ui-consistency.md](./ui-consistency.md)。禁止把大纲叠在创建上面（上下分割）。

### 右栏：图标 TabGroup

一次只显示一组。顶上一行 **仅图标**（窄栏塞不下六段文字），`title` / 悬停出名称；当前项高亮。图标行下方可跟一行小标题（当前 Tab 名）。禁止六个文字 Tab 挤换行，禁止仍用 `<hr>` 把所有面板叠在同一滚动条里。

| Tab | 图标含义 | 内容 |
|-----|----------|------|
| **场景** | 场景 / 画幅 | 场景名称；背景色；剔除背景；**分辨率（预选 + 自定义宽高）**；**出图贴图（标准 / 最高，默认最高）**；「渲染并保存到渲染图」；**导出模型**；**打开渲染文件夹**；**打开导出模型文件夹** |
| **布局模版** | 模版骨架 | 模版下拉；应用；只重排（保留已填元素） |
| **摄影机** | 相机 | 当前看穿的摄像机：透视 / 等距；非等距时 FOV；斜 30/45/60。选中某台摄像机时出现 **贴合视角** 图标 |
| **灯光** | 灯光 | 主光强度、方位角、俯仰、颜色（与现字段一致） |
| **后处理** | 滤镜 | 轮廓描边（开关/色/宽）；暗角 / 辉光 / 曝光 / 对比 / 饱和 / 柔化 |
| **选中物体** | 物件 | **有选中才出现这个 Tab**。无选中：不显示该项，若当前正停在它上面则回到「场景」。内容：空槽提示或变换（移动/旋转/缩放 + XYZ + 缩放滑条 + 从场景删除）；**摄像机**无缩放、有贴合视角图标；**卡牌、卡牌集**有站姿（正面朝上 / 背面朝上）；卡牌集再加形态面板 |

交互：

- 点视口物件（或控制杆）→ 自动切到 **选中物体**
- 点空白取消选中 → 若正停在该 Tab，回到 **场景**
- Tab 选择只记本机会话，不写入 `ProductShot`
- 变换快捷键 W/E/R 仍全局有效，不依赖当前是否在「选中物体」Tab

图标复用 `src/ui/Icons.tsx`；缺的补简单线标，不要另做一套插画。

### 大纲视窗

左栏 **左侧一列**：当前场景里已经存在的物体，对标 Maya Outliner。右边「创建」才是「还能往里放什么」。

分组（仅分组，不做层级父约束）：

| 组 | 来源 |
|----|------|
| 摄像机 | `shot.cameras` |
| 包装盒 | `kind === "box"` |
| 卡牌 | `kind === "card"` |
| 卡牌集 | `kind === "stack"` |
| 板件 | `kind === "board"`（`refId` → `BoardPiece`） |

交互：

- 点一行 = 选中该物体，视口高亮，右栏切到「选中物体」（摄像机则同时可用贴合图标）
- 当前 **看穿** 的摄像机行上有标记（例如小圆点或「看穿」）
- 右键：重命名、删除。摄像机至少留一台；删掉正在看穿的那台则改看另一台
- 点视口物体 ↔ 大纲高亮同步。空槽占位体也出现在对应组

禁止大纲里再烘焙卡面缩略图；名字 + 类型图标即可。

### 左栏：创建（产品栏）

标题就叫 **创建**。Tab 与网格都在这列 **标题下面**，不要和大纲抢同一竖条再叠一层。

**一层 Tab**（一次只加载一组，避免百张卡同时烘焙缩略图把页面卡死）：

| Tab | 内容 |
|-----|------|
| 卡牌集 | 每个 `CardSet` 一张代表图 |
| 单张卡牌 | 二层：先选卡牌集，再显示该集的卡；预览用该卡 fields 渲正面 |
| 板件 | `Project.boards`；缩略为扣形图 |
| 包装盒 | 项目里的盒子 |
| **摄像机** | 排在包装盒 **后面**。不是项目资产库，点「新建摄像机」或拖进视口 → 在场景里生成一台 Maya 式摄像机 |

每组网格用统一 [Pager](./ui-consistency.md)（`1 2 3…n` + 跳转），页大小约 12。禁止一屏渲出整个图鉴。

操作：

- **拖进视口** 或 **点击加入** → 场景里生成一个实例（可重复放）；若当前选中的是模版 **空槽位**，则填入该槽而不是在旁边再堆一件。贴图必须异步：只烘焙刚放入那一件；未完成时先放占位体。禁止同步渲完整卡图把页面卡死
- 拖拽、点击加入、在视口里挪物件 **不得**重新烘焙左栏全部缩略图，也不得把整场景网格重算一遍；只更新被碰到的那一件
- **卡牌 / 卡牌集默认趴在地上**：卡面平行于地面、正面朝上（世界 Y 为高度）。包装盒仍按盒子自己的默认立姿
- **头尾编进网格，不是默认转 Y 180°**：薄片局部空间本身就是「头尾对调后的原始坐标」——趴地、正面朝 +Y，**卡头朝 −Z**（蓝图顶边），卡左朝 −X。新放入的卡牌、卡牌集（含填空槽）`rotationDeg = { 0, 0, 0 }`，控制杆轴向即这套坐标。禁止再靠写入 Y=180 冒充头尾。布局模版里的卡牌集槽位以 **0°** 为底，再叠加模版自己的微调 yaw（例如 -12 就写 -12，不要写成 168）
- **卡面禁止左右镜像**：顶面 UV 与 2D 蓝图左右一致（从 +Y 往下看，U 向右、V 向卡头）。背面贴在 −Y，按印刷翻面处理，从桌下看不得把正面再贴一遍，也不得左右反字。旧实现若用 Y180 或 U 翻转把牌面弄成镜子，一律改网格/UV，不改用户已存的非默认角度
- **卡牌**：按蓝图 `size` + `cornerRadiusMm` 做成圆角薄片，厚度用蓝图卡牌纸厚，侧边颜色用卡芯材质。禁止产品图里用没有圆角的长方体冒充卡牌
- **单卡贴图**：网格 **顶面始终正面**（`frontLayers` + 该卡 fields），**底面始终背面**（`backLayers`）。`item.face` 只改站姿，不换这两张贴图。缺省 `front` 正面朝上；`back` 背面朝上 = 局部先绕 X 180° 再绕 Y 180°（第二下是为了背面图左右不反）。翻过来必须看到背面图，禁止底面透明镂空，也禁止把正面再贴一遍冒充背面。蓝图背面没有任何图层时，底面用卡芯色实心，仍不得透明
- **卡牌集**：见下方「卡牌集形态」。默认仍是一摞实心圆角体。张数来自该集展开后的子集（缺省满集）。**顶面**用子集最上面那张的正面，**底面用该蓝图背面**；四侧用卡芯色。禁止每帧重建网格导致抖动。禁止整摞底面透明、禁止没有背面纹理
- **板件**：用 [boards.md](./boards.md) 的扣形挤出（alpha 镂空 + `thicknessMm`）。禁止再用卡牌圆角矩形冒充。`refId` 指向 `BoardPiece.id`
- **包装盒**：用该盒在包装维度里已经定好的结构 / 贴图（含详细模式天/地 **内壁** 独立图与 UV，无内图则底色） / **倒角** / **材质与工艺遮罩** / **套合轴向**。简单或详细（天地盖）都按包装盒页的设定画：**天+地两只托盘**，不是一只实心方盒；印刷盖底色。产品渲染窗口 **不得**再出现倒角滑条或改 `bevelMm`——倒角只跟那只包装盒绑定，在包装盒结构/渲染页调。详细模式在场景里仍是 **一件**（天+地一起变换）。开合见下方「选中物体」：场景实例可有自己的 `lidOpen`，未写则跟随包装盒页
- **摄像机**：见下方「场景摄像机」。点新建或拖入时，**复制当前视口机位**（Maya Camera from View），生成后选中它，**不自动**改看穿；要出这台机的图，再点贴合视角

### 布局模版

内置若干 **布局骨架**（不是用户可编辑的模版资产）。应用后按槽位生成实例，用户再填具体元素。

至少包括：

| id | 名称 | 槽位 |
|----|------|------|
| `empty` | 空场景 | 无 |
| `box-fan` | 盒 + 扇形卡 | 1 包装盒居中；若干单卡在盒前/周围 **趴地扇形**排开 |
| `box-row` | 盒 + 一字卡 | 1 包装盒居中；若干单卡在盒前 **一字排开**、趴地 |
| `box-stack-fan` | 盒 + 一摞 + 扇开 | 1 包装盒居中；1 卡牌集（一摞）在旁；若干单卡扇开 |

交互：

- 库里新建、或编辑页「应用模版」可选上述布局
- 未填槽位在视口里显示半透明占位体，点选后从左栏指定卡/集/盒
- 也可把左栏物件拖到占位体上完成填入
- 填入后保留用户对位置/旋转/缩放的微调
- 再次应用同一模版：可选「只重排位置、保留已填元素」
- 模版不拥有蓝图/盒子，只写 `items` 的位姿与槽位

### 视口（主流 3D 气质，不是完整 Blender）

与包装盒结构/渲染视口同一套辅助：原点、世界地面网格、RGB 轴 overlay、角落指向性小坐标（前/后/左/右/上/下，随镜头转）、灯光指示。导出 PNG **不含**辅助线、**不含**控制杆、**不含**摄像机锥体、**不含**小坐标。场景预览未就绪时同样盖工作锁。

#### 场景摄像机（Maya）

摄像机是 **场景物体**，不是只有一套隐藏的轨道参数。视口看到的、点「渲染」写出的，都是当前 **看穿（Look Through）** 的那一台。

原理（对标 Maya，不引进 Graph Editor）：

| 项 | 说明 |
|----|------|
| 视线 | 摄像机局部 **−Z** 朝前（Maya）。机身位置 + 欧拉角决定构图 |
| 画幅 | 分辨率红框跟这台机的透视/等距、FOV 走 |
| 视口里 | 未看穿的摄像机画机身 + 锥体（FOV × 画幅比）。正在看穿的那台 **不画自己**（人在机里） |
| 控制杆 | 选中未看穿的机：可移、可转，**不可缩放**（缩放不改变 FOV） |
| 导航 | 看穿某台时，轨道旋转 / 平移 / 推拉都改 **这台机**，等于在机内构图 |

每个场景至少一台。打开旧场景：若没有 `cameras[]`，用现有 `render.camera` 轨道参数生成一台名为 `persp` 的机，并设为看穿。`render.camera` 继续作为这台看穿机的轨道同步（yaw/pitch/distance/target），旧导出路径不丢。

**贴合视角**（选中摄像机后出现摄像机图标，大纲行和「选中物体」/「摄影机」Tab 都有）：把 **当前视口贴到这台机上** = Look Through Selected。之后看到的、渲出来的都是它。再点同一图标或看穿另一台则切换。禁止用「把场景物件整体挪到镜头前」冒充。

视口必须 **一直显示当前看穿的那台摄像机的名字**（不依赖是否选中它）。转镜头、平移、推拉都改这台机，用户不能猜现在控的是哪台。

斜 30 / 45 / 60 只改 **当前看穿机** 的俯仰（保留距离与 FOV）。

#### 摄像机：透视 / 等距

**摄影机 Tab** 编辑 **当前看穿的那台**（见数据模型 `lookThroughId` + `ShotCamera`）：

| 模式 | 说明 |
|------|------|
| **透视** `perspective` | 默认。轨道旋转 + 平移看向点 + 距离 + FOV |
| **等距** `isometric` | 正交投影，无透视缩短；仍可轨道旋转、平移看向点。此模式 **隐藏 FOV** |

切换模式不丢掉物件位姿。

**机位预设**（只改 `camera.pitch` / `yaw`，保留当前 distance 与 FOV；斜视 yaw 取约 38°，与现默认轨道一致）：

| 按钮 | pitch | 观感 |
|------|-------|------|
| 斜 30 | 30° | 偏低侧视 |
| 斜 45 | 45° | 常用产品角 |
| 斜 60 | 60° | 偏俯视 |

点一下立刻跳到该俯仰，仍可轨道拖动微调。完整关键帧与转台序列不在本页；宣传镜头见 [studio.md](./studio.md)。

**地面网格**：产品视口必须画出 Y=0 的世界网格（对标包装盒视口，线要够亮，不能融进背景看不见）。范围随场景加大。原点 RGB 轴、灯光指示仍要。导出 PNG **不含**网格/轴/灯标/控制杆。

#### 视口导航

渲染模式对标 **Unity 场景视图平移 + Maya 轨道**（空白处转镜头，不要和物件控制杆抢）：

| 操作 | 说明 |
|------|------|
| 左键拖空白 | 轨道旋转（绕兴趣点改看穿机的 yaw/pitch） |
| **中键拖（按住滚轮）** | **平移**：沿当前相机的右、上方向移动摄像机与兴趣点（Unity）。不点选、不拖控制杆 |
| **Alt + 左键拖** | 与中键相同的平移（Maya 习惯保留） |
| 滚轮拨动 | 沿视线推拉距离。不是按住滚轮；按住滚轮是平移 |

平移量随当前距离放大，近处细、远处快。等距模式同样平移。禁止用改 FOV 或整场景物件位移冒充平移。中键不得误触发点选或轨道。

页头问号补：中键平移；选中摄像机后点图标把视口贴到那台机。

#### 渲染区域（Resolution Gate）

对标 Maya 的 Resolution Gate：视口里画出 **即将导出的画幅**，不是把整块窗口都当成最终图。

- 画幅比 = `resolutionW : resolutionH`，在视口窗口内 **contain** 居中（窗口更宽则左右留边，更高则上下留边）
- **红线**描画幅四边（约 1–2px，鲜明红，例如 `#e23`）
- **红线以外**铺半透明黑遮罩（约 `rgba(0,0,0,0.45)`），外面的场景仍隐约可见，方便构图，但不能误以为会进导出
- 透视 / 等距的投影 **画幅比跟分辨率走**，不是跟窗口走。红框内所见构图 = 导出构图（辅助线、控制杆、红线、遮罩除外）
- 改分辨率预选或自定义宽高，红框立刻变
- 导出 PNG、剔除背景出图都 **不含** 红线和遮罩，也不含网格 / 轴 / 灯标 / 控制杆 / 摄像机锥体

禁止只画红框却仍按窗口宽高比投影（那样框里对不齐导出）。

#### 分辨率

场景 Tab，字段仍是 `resolutionW` / `resolutionH`（缺省 1920×1080）。

**预选**（点一下写入宽高）：

| 预选 | 像素 |
|------|------|
| HD | 1280 × 720 |
| FHD | 1920 × 1080（缺省） |
| QHD | 2560 × 1440 |
| 4K | 3840 × 2160 |
| 方 1K | 1080 × 1080 |
| 方 2K | 2048 × 2048 |
| 方 4K | 4096 × 4096 |
| 竖 FHD | 1080 × 1920 |
| 竖 QHD | 1440 × 2560 |

预选下面永远有 **宽、高两个可键入数字**（自定义）。整数，**只要大于 0**（上限约 32768，挡住离谱值即可）。**禁止**在键入过程中把数字夹到 256——用户输入 `2560` 时，敲到 `2` 不能变成 `256`。空着或非法时，失焦再落到有效值。键入后若与某预选完全一致，下拉显示该预选；否则下拉显示「自定义」。换预选会覆盖当前宽高。

禁止只有三个死选项、没法填自定义。包装盒单盒渲染页用同一套预选 + 自定义（同一 `BoxRenderSetup` 字段）。

#### 视口贴图 vs 出图贴图

视口要跟手，**允许糊**：卡面用低 DPI 烘焙（大约 56）、场景库缩略更低、板件扣形轮廓可用很粗的采样。不要为了视口流畅把这些糊贴图拿去出成品图。

点「渲染并保存到渲染图」时 **必须重新**按出图质量准备贴图，禁止复用视口缓存。包装盒已经接近原图像素（烘焙最长边上限 4096），卡牌 / 卡牌集 / 板件必须对齐到同一档观感，不能只有盒子清楚、卡和板发糊。

场景 Tab，分辨率下面：**出图贴图**（写入 `render.exportTexture`，缺省 `max`）：

| 档 | 值 | 卡面 | 板件 | 包装盒 |
|----|----|------|------|--------|
| **最高**（缺省） | `max` | 按 **300 DPI** 画正背面（与打印默认 DPI 对齐）；单面最长边不超过 **4096 px** | 贴图用**原图像素**（不要把贴图缩到 96）；扣形轮廓出图用更高采样（最长边大约 512，只影响外形平滑，不影响贴图像素） | 维持现有：原图烘焙，最长边上限 4096 |
| **标准** | `standard` | **150 DPI**，同样 4096 封顶 | 贴图仍用原图；轮廓可比最高略粗 | 同最高 |

禁止把卡面出图停在约 96 DPI（63×88 mm 扑克大约只有 240×330 像素，4K 成品上会明显糊）。视口继续用低 DPI，不跟这个下拉走。

48 张扇形在「最高」时可能较慢、占内存；可出进度/忙状态，不要悄悄降回 96 DPI。单面仍受 4096 边限制。

包装盒单盒渲染页同一套字段与行为。

#### 变换控制杆

选中物件后，视口里必须有与 **Maya / Blender / Unity** 同类的控制杆（gizmo），不能只靠右栏数字：

| 模式 | 控制杆 | 操作 |
|------|--------|------|
| 移动 | RGB 三轴箭头（+ 可选平面方块） | 拖轴沿该轴移；右栏 X/Y/Z mm 同步 |
| 旋转 | RGB 三环 | 拖环绕该轴转；右栏角度同步 |
| 缩放 | 均匀柄（可加轴柄） | 拖改 `scale`；右栏同步 |

- 右栏可切换 移动 / 旋转 / 缩放；快捷键 Unity 式 `W` 移动 / `E` 旋转 / `R` 缩放（输入框内不抢）
- 默认进场景是移动模式；切到 **旋转** 后必须出现 RGB 三环，拖环 **只改 `rotationDeg`**，不得仍在平移
- **世界 / 本地** 两种轴向，所有物件（含摄像机）都要有，可切换：
  - **世界**：红绿蓝对齐世界 XYZ
  - **本地**：红绿蓝对齐该物件当前朝向（摄像机本地 **−Z** 为视线，没有本地轴就没法进退镜头）
- 未选中不显示控制杆
- **转镜头不得丢掉当前选中**：空白处拖轨道 / 中键平移时，选中物件和控制杆还在。只有 **单击空白**（几乎没移动）才取消选中
- 拖控制杆只改当前件，禁止重算全场景网格、禁止卡死
- 导出图不含控制杆

数值栏仍保留，与控制杆双向同步（见 [ui-consistency.md](./ui-consistency.md) 可输入数值栏）。

| 操作 | 说明 |
|------|------|
| 拖移 / 控制杆 / 数值栏 | 位置 X/Y/Z（mm） |
| 旋转 | 绕 X/Y/Z 度；可键入 |
| 缩放 | 统一 scale，默认 1 |
| 删除 | 只删场景实例，不删项目里的蓝图/盒 |
| 开合（仅详细天地盒） | **合上 / 打开** + 滑条。写入该场景实例 `lidOpen`（0 合上～1 打开），不改包装盒页默认开合。未写则跟随包装盒。拖滑条只动天盒位移，不重载贴图 |

灯光、背景、剔除背景：字段与 `BoxRenderSetup` 对齐，便于以后统一。

**禁止**在本页提供包装盒倒角（`bevelMm`）控件。简单方盒没有开合。

### 卡牌集形态

仍是场景里的 **一件物件**（一个控制杆）。选中卡牌集时，右栏变换下方出现本组设置（板件 / 盒不出现）。换形态只改这件内部怎么摆牌，不拆成多个可选中实例。

#### 站姿（卡牌与卡牌集）

选中 **卡牌** 或 **卡牌集** 时，变换区有同一项 **站姿**，写入 `item.face`（不是只给扇形）：

| 值 | 说明 |
|----|------|
| `front` 正面朝上（缺省） | 卡面平行桌面，正面朝世界 +Y |
| `back` 背面朝上 | 仍趴在桌上。局部先绕 X 180° 再绕 Y 180°，让背面朝上且背面图左右不反。**不**把正/背贴图对调 |

牌组 / 错落 / 一字 / 扇形都吃这同一参数。旧数据若没写 `face`、只写了扇形 `fanDir: "down"`，打开时当成背面朝上。

#### 张数区间

渲染默认 **给满**：用该集 `Σ card.qty`（合计 0 时按 1）。

可改成闭区间 **第 from ～ to 张**（1-based）。按数据集顺序把每张卡的 `qty` 展开成牌序，只取这一段。

| 规则 | 说明 |
|------|------|
| 缺省 | 不写 from/to = 满集 |
| 夹紧 | from/to 夹到 `1…N`（N = Σqty，至少 1）；from > to 则对调 |
| 用途 | 牌组厚度、错落/一字/扇形的张数、顶面用哪张，都只用这段 |
| 右栏 | 两个数字「从」「到」+ 提示「本集共 N 张」 |

不改卡牌集数据本身，只影响这一件场景实例。

#### 形态

| 形态 | `shape` | 外观 |
|------|---------|------|
| **牌组** | `deck`（默认） | 现在这样：一块圆角挤出。厚度 = 区间张数 × 纸厚。**不**逐张分层 |
| **错落** | `messy` | 仍是一摞，但不是齐的方盒子：每张有确定性的平移和绕竖轴小转角，能看见参差。强度 0–1，缺省 0.4 |
| **一字排开** | `row` | 沿物件局部 X 排开，卡面仍朝上。**间距** `gapMm`：相邻卡中心距 = 卡短边宽 + gapMm；可负数（重叠）。缺省 4。**排开方向**见下 |
| **扇形** | `fan` | 见下 |

**排开方向** `spread`（一字、扇形共用；叠放仍是从上到下，后铺的压在上面）：

| 值 | 说明 |
|----|------|
| `ltr` 从左到右（缺省） | 当前默认：牌序沿局部 +X / 扇弧从左铺到右 |
| `rtl` 从右到左 | 水平反向：牌序从右铺到左；叠放不变（仍从上到下） |

右栏在一字、扇形下用同一下拉「排开：从左到右 / 从右到左」。实现上把局部 X（一字）或弧参数 t / yaw（扇形）取反，再走原来的躺平与居中。不要靠把整件物件 yaw 180° 冒充反向（那会把头尾也转掉）。

**扇形另有扇叶朝向**，不要和排开方向、站姿混：

| 字段 | 说明 |
|------|------|
| **扇叶** `fanLeaf` | `bottomUp` 从下到上（缺省）：牌序沿弧铺、后铺的在上。`topDown` 从上到下：弧向叠放反过来。与 `spread` 正交：上下叠放 × 左右排开 |

扇形用 **两段弧** 控制展开，并要有 **间距**（与一字共用 `gapMm`，缺省 4；加在上弧上，正数更开、负数更挤）：

| 字段 | 说明 |
|------|------|
| **下弧宽** `fanInnerMm` | 聚拢端（卡尾、下缘）的弦宽。缺省约卡短边 × 0.6 |
| **上弧长** `fanOuterMm` | 张开端（卡头、上缘）沿圆弧的弧长。缺省至少约卡长边 × 2.8 |
| **间距** `gapMm` | 扇叶之间额外弧长 |

扇形 **张开朝局部 −Z**（与一字排开、单卡的卡头同向）。卡头在外缘上弧、卡尾聚在内缘下弧。禁止靠物件再写 Y=180 才摆正，也禁止卡头对着聚拢端导致「下弧宽」实际在改上缘。

内半径、张角由下弧宽、上弧长、间距和卡长边解出。旧数据若只有 `fanDeg`，打开时换算成弧，不丢展开。

一字 / 扇形每张仍按层厚错开，避免共面；错开后会成阶梯。要用 **倾斜把阶梯躺回桌面**：绕「首尾连线水平方向」把高度差转平，使整体贴地，牌面只留很小倾角。背面朝上（`item.face`）在躺平、居中之后再套局部 Rx180+Ry180。

**控制杆**（一字、扇形）：原点必须在这件物体的几何中心（各卡中心的质心），不要钉在第一张牌或阶梯一端。贴地高度按躺平后的最低点计算。

错落的偏移/转角必须由 `item.id` + 张序号 **算死**，禁止每帧随机，禁止静止时抖。

#### 逐张时的网格

错落 / 一字 / 扇形才逐张圆角薄片：每张顶面 = 该卡正面，底面 = 蓝图背面（与单卡相同，不因背面朝上而对调贴图）。

层厚 = `max(纸厚, 1.2mm)`。单张 0.32mm 在透视相机里会被深度缓冲吃成一张纸，错落看起来会「变薄」；加层厚后侧边（卡芯色）要能看见，错落总高按层厚累加。

- **上限 48 张**。区间更长时只画这段的前 48 张，右栏提示「只显示 48 / M」
- 整形成形相对物件原点，移动/旋转/缩放这件卡牌集时整体走
- 禁止为了形态去模拟弯曲、重力、碰撞

**描边**

| 字段 | 说明 |
|------|------|
| 开关 | 默认关 |
| 颜色 | ColorField |
| 宽度 | 像素，轮廓外描 |

### 导出

与包装盒渲染相同：PNG；分辨率按场景 Tab 当前宽高；有工程路径则写入 **`渲染图/`**，否则浏览器下载。文件名带场景名与时间戳。导出图是红框内那张，不含红线、遮罩、辅助线、控制杆、**摄像机锥体**。构图来自当前看穿的摄像机。

出图前按上一节 **出图贴图** 重烘焙卡面 / 板件 / 盒子贴图。视口糊、出图清。

**打开渲染文件夹**：场景 Tab 与页头导出旁提供按钮。已绑定工程路径时，在资源管理器 / Finder 中打开 `渲染图/`（没有就先建再打开）。未绑定：提示去绑定工程文件夹，不要假装打开成功。序列帧目录由 [影棚](./studio.md) 打开，不要在本页再放「渲染序列帧」。

### 导出模型（给 Maya）

影棚只做模版镜头。自由布光、多机位、Arnold / V-Ray 去 Maya。本页把 **当前场景已经摆好的几何** 交出去，不要在工坊里再造一套 DCC。

入口：场景 Tab **导出模型**（页头可放同一动作）。与「渲染并保存到渲染图」分开，不要合成一个按钮。

| 项 | 规格 |
|----|------|
| 格式 | **ASCII FBX**（无动画、无骨骼）。Maya：`File > Import`，选 `.fbx`。贴图在同目录 `textures/`，FBX 用相对路径引用。不要交半残二进制 / 带动画曲线的 FBX。OBJ+MTL 不再作为给 Maya 的主格式（实现可不再写） |
| 宿主 | 已绑定工程文件夹：写入 `导出模型/{场景名}/`。未绑定：打成 zip 浏览器下载，并提示去绑定 |
| 文件 | `{场景名}.fbx`、`textures/`（漫反射 PNG）、`场景说明.txt` |
| 单位 | **1 单位 = 1 厘米**（内部毫米 ÷10）。Maya 默认厘米，63×88 mm 卡导入后是 6.3×8.8 |
| 轴向 | 与视口相同：Y 向上、右手系。不要偷偷改成 Z-up |
| 几何 | 当前视口同一套网格（`shotResolve` / `boxDraw`，保留 `coverBase` 那套拆件）。**禁止**再 tessellate 一套盒子。开合、形态、位姿 **烘焙进网格**（天/地是两个 object；卡牌集按当前形态：牌组一块，错落/一字/扇形逐张） |
| 命名 | 可读且稳定：`box_{盒名}_lid` / `_base` / `_simple`；`card_{蓝图名}`；`stack_{集名}_{序号}`；`board_{板名}`。空槽、占位体 **不导出** |
| 贴图 | 按当前 **出图贴图** 档烘焙漫反射（默认最高，与静帧出图同一档），写入 `textures/`，FBX 材质 `Diffuse` 相对路径。卡正/背、板件、盒外壁/内壁各一份材质。烫金/UV 遮罩本期只当额外 PNG 旁路拷贝（`*_foil.png` / `*_varnish.png`，能拷就拷），**不**保证变成 Maya 金属节点 |
| 不含 | 地面网格、轴、红框、控制杆、摄像机锥体、空槽。后期滤镜（描边/暗角）不是几何，不进 FBX |
| 摄像机 / 灯 | FBX 第一期也不写可播放摄像机。写进 `场景说明.txt`：看穿机名称、眼睛位置 cm、target、FOV、透视/等距；其余 `cameras[]` 各一行；主光 yaw/pitch/强度/颜色、补光、环境、背景色。给人在 Maya 里对一下，不是可播放的 `.ma` |
| 空场景 | 按钮禁用，写「场景里还没有物件」 |
| 进度 | 工作锁「正在导出模型」；结束打开该文件夹（已绑定）。覆盖同名目录里的旧文件 |

「打开导出模型文件夹」：已绑定则打开 `导出模型/`（没有就先建）；未绑定要提示。

影棚同一套导出器：见 [studio.md](./studio.md)，导出的是 **当前播放头** 的演员+布景，不是产品场景的静帧拷贝。

一个项目可有 **0～多个** 产品场景。打开项目或进入产品渲染页都 **不要**偷偷建场景。

会话：当前 `shotId`、是在库还是编辑器（对标包装盒 `boxLibraryOpen`）。

卡牌纸厚与卡芯在 **卡牌规格** 里调（蓝图只选规格与横竖），产品渲染只读取蓝图上同步后的副本，不在本页改规格。

打开旧工程：若卡牌集实例 `rotationDeg` **精确等于** `{ x: 0, y: 180, z: 0 }`（上一版默认写入），改成 `{ 0, 0, 0 }`，因为头尾已编进网格。用户手改过的其它角度不动。单卡不迁移。

## 验收标准

- [ ] 进入产品渲染先看到场景预览块库；空库不自动创建并跳进编辑；点块才进内部编辑；可返回库
- [ ] 页头矮，教学在问号里，不占大段副标题
- [ ] 左栏 **大纲与创建左右并列**；大纲列出摄像机/盒/卡/集/板，点选与视口同步，看穿机有标记
- [ ] 创建标题下方才是卡牌集 / 单张卡 / 板件 / 包装盒 / 摄像机；单卡先选自集；网格数字翻页
- [ ] 可新建 Maya 式摄像机（复制当前机位）；视口画未看穿机的锥体；导出图没有锥体
- [ ] 视口标明当前看穿的摄像机名称；选中后贴合视角图标把视口与渲染都改看这台机
- [ ] 左右栏边框可拖改宽度；大纲与创建可拖分割
- [ ] 摄像机可切换透视 / 等距
- [ ] 选中物件后视口有移动/旋转/缩放控制杆，且可切 **世界 / 本地** 轴向；摄像机同样有本地轴；切到旋转后拖环改角度；导出图没有控制杆和辅助线
- [ ] 空白拖轨道或中键平移 **不取消选中**；单击空白才取消
- [ ] 分辨率有 HD/FHD/QHD/4K、方图、竖图预选，以及可键入的自定义宽高（大于 0；键入中途不夹到 256）
- [ ] 视口卡面/板件可以糊；点渲染出的 PNG 用出图贴图（默认最高：卡 300 DPI、板件原图像素），不得复用视口低 DPI 缓存；盒子与卡/板清晰度同一档
- [ ] 场景 Tab 有出图贴图「标准 / 最高」，缺省最高；换档只影响下一次出图，不把视口拖慢
- [ ] 场景库预览块能看出场景内容（低质量三维缩略），不是只有文字计数
- [ ] 新放入的卡牌、卡牌集默认趴在地上（卡面平行地面、正面朝上）
- [ ] 卡/集局部坐标已把头尾编进网格；新放入 `rotationDeg` 为 `{0,0,0}`，不再默认写 Y=180
- [ ] 卡面与 2D 蓝图左右一致，不得镜像反字；翻到底面是背面
- [ ] 摄影机 Tab 有斜 30 / 斜 45 / 斜 60 机位；地面网格可见；导出图没有辅助线
- [ ] 中键拖平移镜头（Unity）；Alt+左键同样平移；空白左键仍轨道旋转；滚轮拨动推拉
- [ ] 视口有分辨率红框（画幅比=导出分辨率），框外半透明黑；红框内构图与导出一致；导出图没有红线和遮罩
- [ ] 单卡与卡牌集 3D 网格使用蓝图圆角，不是方块
- [ ] 卡牌集默认牌组形态高度随区间张数 × 纸厚变化；未设区间则满集 `Σ qty`
- [ ] 选中卡牌或卡牌集可设站姿：正面朝上 / 背面朝上（默认正面）；背面朝上后背面图左右不反
- [ ] 选中卡牌集可设张数 from–to，以及形态：牌组 / 错落 / 一字（间距、左右排开）/ 扇形（扇叶上下、左右排开、下弧宽、上弧长、间距）
- [ ] 扇形张开朝局部 −Z，与一字排开卡头同向，`rotationDeg` 为 0 即正，不必再绕 Y 180°；卡头在外缘上弧、卡尾聚在下弧；下弧宽改下缘、上弧长改上缘
- [ ] 一字/扇形「从右到左」是牌序水平反向，叠放仍从上到下；不是整件 yaw 180°
- [ ] 错落不是齐盒子，单张层厚可见（不少于 1.2mm）；一字/扇形按层厚错开后躺平贴地，控制杆在几何中心
- [ ] 右栏为图标 TabGroup：场景 / 布局模版 / 摄影机 / 灯光 / 后处理；有选中才出现「选中物体」，点选物件自动切到该 Tab
- [ ] 错落/一字/扇形逐张薄片、顶底贴图正确；超过 48 张截断；静止不抖
- [ ] 白芯卡侧边为白灰色；黑芯为深灰（读蓝图材质）
- [ ] 产品渲染页没有包装盒倒角参数；场景里的盒子倒角与包装盒编辑器里的一致
- [ ] 详细天地盒在产品视口按天+地+内外壁画，印刷盖底色；贴图未就绪时也是托盘结构，不是一只实心方盒
- [ ] 选中详细包装盒时，选中物体栏有合上 / 打开（及滑条）；只改该场景实例，包装盒页默认开合不变
- [ ] 可应用至少「盒+扇形卡」「盒+一字卡」布局模版，再填入自己的盒/卡
- [ ] 可把物件放进场景并调位置、旋转、缩放；拖入单卡不得卡死页面（异步贴图，不重渲左栏缩略图）
- [ ] 单卡翻面能看到蓝图背面；卡牌集底面是背面纹理，都不得透明镂空
- [ ] 卡牌集在视口内静止时不抖动、不闪、不每帧跳网格
- [ ] 视口有原点 / 网格 / 轴 / 灯光指示 / 角落前左右小坐标；导出图没有这些辅助
- [ ] 可开关轮廓描边（色 + 宽）
- [ ] 可调暗角 / 辉光 / 色彩 / 柔化
- [ ] 导出 PNG 到 `渲染图/`（或未绑定时下载）；构图来自当前看穿摄像机
- [ ] 已绑定工程时可「打开渲染文件夹」进 `渲染图/`；未绑定要提示，不能假成功
- [ ] 场景随项目保存
- [ ] 场景 Tab 可「导出模型」：已绑定则写入 `导出模型/{场景名}/`（fbx+textures+场景说明.txt）；Maya 能 Import 出与视口一致的盒/卡/板（开合与形态已烘焙）；单位厘米、Y-up
- [ ] 导出模型不含辅助线/红框/空槽；贴图按出图档；空场景不能导
- [ ] 已绑定可打开 `导出模型/`；未绑定改为 zip 下载并提示绑定，不能假成功
- [ ] 本页没有「渲染序列帧」；静帧导出仍写入 `渲染图/`

## 已知限制 / 不做

- 完整关键帧 / 摄像机路径编辑器不做；宣传镜头（转台、开盒、卡牌排列）在 [影棚](./studio.md)，不在本页
- 不做复杂材质节点、环境 HDR 贴图库
- 不做用户自定义布局模版编辑器（只提供内置骨架）
- 牌组形态不逐张分层；错落/一字/扇形逐张但不模拟弯曲、重力、碰撞；单件最多画 48 张
- 滤镜以好看的产品图为准，不保证摄影科学
- 不内置导出 mp4 / mov
- 模型导出是 ASCII FBX 当前帧，不是带动画曲线的 FBX，也不是给 Maya 的主格式 OBJ
- 出图贴图「最高」仍受单面 4096 px 与卡牌集 48 张上限；不是胶片级扫描

# 影棚

> 给传统宣传片出 **镜头素材**：选模版、填演员、拧秒数，写出 PNG 序列，拿到剪映 / PR / AE 里成片。  
> **不是**产品渲染的附属按钮，也 **不是**剪辑软件。  
> **入口与蓝图 / 包装盒 / 产品渲染一致**：先看预览块，再点进棚。

与 [product-render.md](./product-render.md) 的分工：产品渲染摆静帧、出海报；影棚演一场有剧本的戏、出序列。日常在 [桌面客户端](./desktop-app.md) 里跑。

## 用户故事

- 作为要做淘宝 / 众筹 / 视频号宣传片的人，我希望单独有一个「影棚」库，不要和静帧场景混在一起。
- 作为设计者，我希望新建影棚时先选模版（开盒转台、盒转台、卡牌排列、分批亮相），而不是掉进空白三维场景。
- 作为设计者，我希望模版告诉我缺哪个演员；开盒转台必须填详细天地盒，简单方盒要被拒绝并说明原因。
- 作为设计者，我希望把已经摆好的产品场景当成布景垫在后面，演员在模版槽位上演戏。
- 作为设计者，我希望只拧开盒速度、转台速度、每批张数，能预览整段戏，再渲成 PNG 序列交给剪辑。
- 作为设计者，我希望影棚有和产品渲染同一套灯光、FOV、透视/等距、分辨率，不要只有播放条。
- 作为设计者，我希望操作机（自己转着看）和渲染机（序列真正用的那台）分开；能看见渲染机转台轨迹。
- 作为设计者，我希望转台时主光可以跟着转，也可以钉在世界里。
- 作为设计者，我希望开盒时天地盒整体仍居中，不要地盒钉死、天盒往外冒。
- 作为设计者，我希望演员能调卡牌集形态、天地盒开合，和产品渲染选中物体同一套，不要模版里再藏一套残缺控件。
- 作为设计者，我希望影棚不够用时，能把当前这一帧的演员+布景导出成 Maya 能打开的模型，去外面接着渲。

## 范围

**做**：影棚库（预览块）；新建先选模版；第一批四个模版；演员槽（验类型）+ **与产品渲染对齐的演员设置**（卡牌集形态、天地盒开合）；布景；秒数旋钮；**操作机 / 渲染机**（渲染机轨迹）；灯光与 FOV 等同产品渲染；转台 **主光跟随**；开盒 **整体居中**；播放条；分辨率红框与出图贴图；桌面写出 PNG 序列 + 镜头表；**导出当前帧模型（与产品渲染同一套 FBX）**。

**后期做（已确认方向，不跟第一期）**：

- 更多模版（例如开盒后牌从盒口扇出）
- 成片清单（多个影棚按宣传片顺序批量渲）
- 导入 GLB / FBX 当死布景网格
- 把已写出的 PNG 压成预览小 mp4（仍不是交付成片）

**不做**：时间轴剪辑、字幕、配乐、转场、Graph Editor、多物件独立关键帧、运动模糊、**可编辑摄像机曲线**（转台只画圆/弧轨迹，不能拖点）、内置编码交付 mp4、自由控制杆摆演员、在影棚里改包装倒角 / UV / 卡面图层、浏览器标签跑序列、任意多台 Maya 摄像机（只有操作机 + 渲染机两台）。

产品渲染页 **不再**提供「渲染序列帧」。旧数据若有 `ProductShot.sequence`，打开忽略，不要实现那套按钮。

## 与产品渲染

| | 产品渲染 | 影棚 |
|--|----------|------|
| 入口 | 项目级「产品渲染」 | 项目级「影棚」（并列，不要嵌进场景 Tab） |
| 预览块 | 场景静帧缩略 | 代表帧或循环小预览 + 模版名；缺演员要看得出 |
| 主操作 | 大纲、创建、控制杆、多机位 | 演员槽、布景、模版旋钮、播放条 |
| 产出 | `渲染图/` 一张 PNG；`导出模型/{场景名}/` FBX | `序列帧/影棚名/` PNG 序列 + 镜头表；当前帧也可导出 FBX |
| 引用关系 | 不引用影棚 | 可引用一个 `ProductShot` 当冻结布景 |

路由建议 `/project/studio`。禁止占用现有 `/project/stage`（那是对战「舞台」）。

实现上仍走包装 / 产品同一套 `BoxGl.drawScene`：演员盒子走 `boxDraw`（保留 `coverBase`），卡牌集走产品渲染已有的形态网格，布景走 `shotResolve` 组合结果。禁止为影棚再写一套 tray / shader。

## 界面与交互

### 库：预览块 → 再进入棚

工作区点「影棚」后，**先进入影棚库**，不要直接丢进某一个棚。

- 每个 `Studio` 一张 **预览块**（低质量三维代表帧或短循环 + 名称 + 模版名）。未填必填演员时块上标明缺什么（例如「缺天地盒」），禁止只有「空影棚」两字、也禁止整块空白。
- 点击预览块 → 进入该棚（演员 / 布景 / 视口 / 旋钮）
- 顶栏或库内：**新建影棚** → **先选模版**（见下），再建块并进入
- 右键：重命名、复制、删除（可删到 0 个）
- 编辑器内：**返回库**

空项目：库为空态 + 「新建影棚」。**不要**进本页时偷偷建一个并跳进编辑。

页头矮，教学进问号，见 [ui-consistency.md](./ui-consistency.md)。

### 新建：先选模版

点「新建影棚」先出模版选择（预览块或列表，带一句剧本说明），选中后才生成 `Studio`。禁止先建空白自由场景再「挂一个动画」。

换模版（编辑页也可换）：槽类型仍匹配的演员留下；不匹配的清空并提示；旋钮落到新模版缺省。不要无声丢掉已填的盒。

### 编辑页布局

| 区域 | 内容 |
|------|------|
| 左栏 **演员** | 当前模版的槽位列表（必填 / 选填、已填 / 空）。点空槽从下方候选填入 |
| 左栏 **布景** | 无 / 纯色 / 产品场景。产品场景用项目里已有 `ProductShot` 列表（名称 + 小缩略） |
| 中央 | 三维视口 + 底边 **播放条**（播 / 停 / 进度）。左上写模版名 |
| 右栏 | **图标 TabGroup**（与产品渲染同一套习惯）：场景 / 灯光 / 摄影机 / 模版；**有选中演员槽才出现「演员」** |

左右栏可拖宽度，见 [ui-consistency.md](./ui-consistency.md)。

禁止：Maya 式自由大纲当主交互、演员控制杆、在本页调倒角 / UV / 卡面。构图：操作机随便转着看；**序列只吃渲染机**。演员位姿仍由模版槽位决定。

左栏填演员：只列出 **该槽收得下的** 项目资产（开盒槽只列 `mode === "lidBase"` 的盒；卡槽只列卡牌集）。点选或拖到槽上填入。已填可清除。类型不对：槽位保持空，并写原因（例如「这个模版需要详细天地盒，简单方盒不能开盖」）。点已填或空槽 → 视为选中该槽，右栏切到 **演员** Tab。

### 右栏：图标 TabGroup

一次只显示一组。顶上一行仅图标，与 [product-render.md](./product-render.md) 同一套 `Icons`。禁止再把灯/机/模版/导出搓成一长列。

| Tab | 内容 |
|-----|------|
| **场景** | 名称；背景色；剔除背景；分辨率预选 + 自定义；出图贴图标准/最高；帧率；「渲染镜头」；**导出模型**；打开序列帧文件夹；打开导出模型文件夹 |
| **灯光** | 与产品渲染同一套：主光强度、方位角、俯仰、颜色（ColorField）；补光、环境光。转台类模版另有 **主光跟随转台**（见下） |
| **摄影机** | **操作机 / 渲染机** 切换看穿；各自透视/等距、FOV、斜 30/45/60。看穿哪台，空白拖轨道就改哪台 |
| **模版** | 只留这场戏的时间旋钮（开盒秒、转台秒、圈数、边开边转、展开秒、每批张数…）。**不要**在这里再做一份卡牌形态 |
| **演员** | **有选中槽才出现**。无选中则该项隐藏。内容与产品渲染「选中物体」对齐，见下「演员设置」 |

点视口空白不取消槽选中（转镜头也不取消）。点左栏另一槽才换选中。

### 操作机与渲染机

影棚固定 **两台轨道机**，不是产品渲染那种可新建 N 台摄像机。

| 机 | 字段 | 干什么 |
|----|------|--------|
| **操作机** | `viewCamera` | 自己转着看、对位布景。序列 **不吃** 这台 |
| **渲染机** | `render.camera`（rest）+ `render.projection` | 序列每一帧的构图从这台出发；转台是给这台加偏航 |

操作机的透视/等距写在 `viewCamera.projection`；渲染机写在 `render.projection`（`BoxRenderSetup` 原字段，不要另开一份）。

视口左上写当前看穿：「看穿：操作机」或「看穿：渲染机」。红框画幅永远跟 **渲染机** 的透视/等距/FOV 走（操作机只是观察，避免红框跟手乱跳让人以为改了出片）。导出序列构图 = 渲染机 + 模版动画（转台偏航等）。

交互：

- **贴合操作机 / 贴合渲染机**：把视口看穿切到那台（对标产品渲染 Look Through）。空白左键轨道、中键平移、滚轮推拉都改 **当前看穿的那台**
- 看穿操作机时：视口里必须画出 **渲染机机身 + 锥体**，以及它的 **行动轨迹**（见下）
- 看穿渲染机时：不画自己机身（人在机里）；轨迹仍画（圆/弧铺在兴趣点周围），播放头位置用小点或一截锥体标出
- 斜 30/45/60、FOV、透视/等距：编辑的是 **当前看穿机**；摄影机 Tab 同时列出另一台的只读摘要（或可点选切换）
- 第一次引用产品场景当布景：把该场景看穿机轨道 **同时复制** 到操作机和渲染机（仅这一次）。之后在操作机里转镜头 **不得**改渲染机

打开旧影棚：没有 `viewCamera` 时，把当时的 `render.camera` 复制一份给操作机，看穿默认 **操作机**（避免再转视口把已经对准的渲染构图转丢）。

#### 渲染机轨迹

转台类模版（`unbox-turntable`、`box-turntable`）必须在视口画出渲染机将要走的路：

- 轨迹 = 绕 `render.camera.target` 的水平圆（或 `turns` 不足 1 时为弧），半径 = 渲染机眼睛到 target 的水平距离，高度随 pitch 钉在轨道平面上
- 缺省一圈；`turns` 为 0.5 则只画半圆
- 播放头在轨迹上有标记（当前帧渲染机所在处）
- 线色鲜明（例如浅黄），约 1–2px；**导出序列不含**轨迹、机身、锥体、红框、辅助线

非转台模版（排列/分批）：渲染机不动，仍画机身+锥体，不画圆。

禁止用「把演员整体旋转」冒充转台轨迹。

### 灯光（与产品渲染对齐）

场景灯光字段与 `BoxRenderSetup.lights` 相同，控件照抄产品渲染灯光 Tab：主光强度 / yaw / pitch / ColorField，补光，环境光。改灯立刻出画，不出工作锁、不重载贴图。

**主光跟随转台** `lightsFollowTurn`（缺省关），仅开盒转台 / 盒转台显示：

- 关：灯钉在世界里，镜头绕产品转（产品上的高光会扫过）
- 开：主光 yaw 与渲染机转台偏航 **同步增加**（rest 灯方向 + 当前转台 Δyaw）。产品看起来像转盘上的灯架一起转
- 只影响预览和序列每一帧的 uniform；**不准**写进贴图 cache key，不准出工作锁

### 开盒：整体居中

开盒转台里天盒仍只沿套合轴平移、不翻转，网格仍按 **合盖** 建。

与包装页/产品渲染默认不同的是 **居中方式**：

- 禁止：地盒钉在槽位原点、天盒往外冒，视觉中心跟着天盒跑掉
- 必须：合盖时整体中心在槽位原点；打开过程中 **天+地合起来的包围盒中心** 始终留在槽位原点（compose 时给整件演员加补偿位移，通常是把抬升量分一半给天、一半反向给地，或先抬天再平移整件）
- 只在影棚 compose；**不改**包装盒页的 `lidOpen` 默认，不改 `boxLidLiftVec` 的包装预览

盒转台模版若演员开合 > 0，同样用整体居中，避免打开后盒子「偏到画面上方」。

### 演员设置

左栏点选槽位后，右栏 **演员** Tab 与产品渲染「选中物体」同一套语义（控件可复用 ShotPage 那一块，不要再发明第三套）。

**盒槽**（详细天地盖才有开合；简单方盒不出现开合）：

| 项 | 说明 |
|----|------|
| 开合 | 合上 / 打开 + 滑条。写入该演员 `lidOpen`（0～1）。盒转台：转台全程保持这个开合。开盒转台：播放头仍 0→1 做开盖，滑条表示 **开场**（播放头=0 时的开合）；不要另做终态滑条 |

**牌槽**（卡牌集）：

与产品渲染卡牌集相同：站姿 `face`；张数从–到；形态牌组 / 错落 / 一字 / 扇形（间距、排开、扇叶、下弧宽、上弧长、错落强度）。写入该演员 `stack` / `face`。上限仍 48 张。

排列展开：终态 = 演员当前 `stack`（不要模版里再做「终态扇/一字」下拉）。t=0 仍从收拢插值到该终态；若终态是牌组，展开过程仍用逐张薄片收到齐摞。

分批亮相：已出现的牌落在演员 `stack` 的终态位置；未出现的不画。

禁止在影棚改倒角、UV、卡面图层。

### 第一批模版

内置，用户不能自造模版编辑器。

| id | 名称 | 剧本 | 必填演员 | 选填 |
|----|------|------|----------|------|
| `unbox-turntable` | 开盒转台 | 先开盖（或边开边转），再绕兴趣点转指定圈数 | **盒** `box`：必须是详细天地盖 | — |
| `box-turntable` | 盒转台 | 只转不拆 | **盒** `box`：简单或详细都可以 | — |
| `card-spread` | 排列展开 | 卡牌集从收拢插值到演员 `stack` 终态 | **牌** `stack`：一个卡牌集 | — |
| `card-batch` | 分批亮相 | 按牌序一批一批出现在终态排列上 | **牌** `stack`：一个卡牌集 | — |

「开盒后牌从盒里扇出」**不**在第一批，单独立项。

#### 槽位规则

| 槽 `slotId` | `kind` | 校验 |
|-------------|--------|------|
| `box` | `"box"` | `refId` → `PackagingBox`。`unbox-turntable` 时该盒 `mode` 必须是 `lidBase`；`simple` 或找不到盒 = 槽无效 |
| `stack` | `"stack"` | `refId` → `CardSet`。找不到 = 槽无效 |

同一影棚同一 `slotId` 只能有一条演员。换演员只改 `refId`，不在棚里复制出第二只盒。

倒角、贴图、壁厚、卡面图层仍只在包装盒 / 卡牌页改；影棚只引用。

必填槽无效时：**禁用「渲染镜头」**，播放条仍可拖（空槽画占位体），右栏写清缺哪一槽。

### 布景

布景 **不起演**，没有控制杆，点不中。

| `backdrop.kind` | 说明 |
|-----------------|------|
| `none`（缺省） | 只用影棚自己的背景色 / 地面；可剔除背景出透明序列 |
| `color` | 纯色背景（ColorField）；与 `none` 的差别是明确垫一块色，不做产品场景 |
| `shot` | **引用**一个已有 `ProductShot`（写 `shotId`）。把该场景里的物件按保存的位姿冻进去当环境 |

引用产品场景时：

- 只取该场景的 **物件**（盒 / 卡 / 集 / 板）和它们已存的位姿、开合、卡牌集形态。不看穿该场景的摄像机来出片（影棚用自己的机位）
- **第一次选中某场景当布景**：把该场景当前看穿机的轨道 **同时复制** 到本影棚的 **操作机和渲染机**（仅这一次）。之后转操作机不改渲染机，也不回写产品场景
- 灯光、背景色、分辨率以 **影棚** `render` 为准，不跟场景走（避免转台灯光和静帧绑死）
- 布景里若有物件与已填演员 **同一 `kind` + `refId`**（同一只盒、同一个卡牌集），**布景里不画那一件**，避免双影。单卡按 `setId`+`cardId` 比
- 场景被删或 `shotId` 找不到：布景标「场景丢失」，仍画演员；不要把影棚整页作废
- 布景贴图未就绪：占位体，盖工作锁（读图是质变）；就绪后拿掉
- 禁止在影棚里移动 / 删除布景物件。要对齐桌面：去产品渲染改那个场景，或把模版演员放在原点、场景往原点摆

`none` / `color` 与剔除背景：开剔除则序列透明底，便于剪辑叠台面。引用场景且剔除背景时，不画影棚底色，布景物件仍画。

导入 GLB 当桌子：**第一期不做**。

### 模版旋钮

用户拧的是 **秒** 和 **数量**，不是帧曲线。帧率只影响写出多少张。

**开盒转台**（`unbox-turntable`）

| 旋钮 | 缺省 | 说明 |
|------|------|------|
| 开盒秒数 | 1.5 | 开合从演员开场值插到 1，天盒位移；整体居中 |
| 转台秒数 | 4 | **渲染机**绕自己的 `target` 偏航 |
| 圈数 | 1 | 正数；渲染机 yaw 从 rest 转到 +360°×圈数 |
| 边开边转 | 关 | 关：先开完再转。开：两段从 0 秒同时开始，总时长取较长者 |
| 主光跟随转台 | 关 | 见灯光；写在灯光 Tab，这里不重复也可以，两处同一字段 |

**盒转台**（`box-turntable`）

| 旋钮 | 缺省 | 说明 |
|------|------|------|
| 转台秒数 | 4 | 渲染机偏航 |
| 圈数 | 1 | 同上 |
| 主光跟随转台 | 关 | 同上 |

盒转台开合读演员 `lidOpen`，不自动打开。简单盒没有开合。

**排列展开**（`card-spread`）

| 旋钮 | 缺省 | 说明 |
|------|------|------|
| 展开秒数 | 2 | 从收拢插值到 **演员 `stack` 终态** |

终态形态、排开、张数、弧/间距一律在演员 Tab，不在模版 Tab 再做一份。

展开过程 **一律逐张薄片**：t=0 收拢（间距/弧接近 0），t=1 为演员终态。站姿、头尾与产品渲染相同。

**分批亮相**（`card-batch`）

| 旋钮 | 缺省 | 说明 |
|------|------|------|
| 每批张数 | 8 | ≥1；按牌序切批 |
| 批间隔秒 | 0.8 | 每批出现后等到下一批；最后一批仍占满这一段 |

终态排列读演员 `stack`。未出现的牌不画。批次数 = `ceil(区间张数 / 每批张数)`（截到 48）。总时长 = 批次数 × 批间隔。

所有秒数 > 0，圈数 > 0；键入非法失焦再落到缺省。滑条用 `patchProject` 的 `mergeKey`（如 `studio-unbox`），预览跟手。

### 时长与播放条

总时长由当前模版算死（开盒转台见上；盒转台 = 转台秒数；排列 = 展开秒数；分批 = 批次数 × 间隔）。

播放条 0…总时长。播、停、拖进度。拖进度只改：开合、**渲染机**偏航、主光跟随、展开参数、可见张数。**立刻出画**：不上工作锁、不重载贴图、不重建合盖网格。看穿操作机时，播放条仍驱动渲染机在轨迹上走，操作机自己不动。

视口糊、跟手即可。不要为了预览按出图 DPI 烘焙。

### 视口

与产品渲染同一套辅助：地面网格、轴、分辨率红框、角落小坐标、轨道旋转 / 中键平移 / 滚轮推拉。导出序列 **不含**辅助线、红框、播放条、空槽占位体、**渲染机机身/锥体/轨迹**。

红框画幅比跟 **渲染机** 走。看穿操作机时，红框仍是渲染机将要出的画幅（操作机只是在旁边看），避免误以为操作机 FOV 会进序列。

空槽：半透明占位（盒槽像盒子，牌槽像一摞牌），标明槽名。

灯光、背景、剔除背景、分辨率预选 + 自定义、出图贴图标准/最高：字段与 `BoxRenderSetup` 对齐，控件与 [product-render.md](./product-render.md) 相同，必须都能调。换分辨率红框立刻变。

### 导出：序列帧

入口：右栏「渲染镜头」，与产品渲染「渲染并保存到渲染图」分开。

| 项 | 规格 |
|----|------|
| 宿主 | **仅桌面客户端**。浏览器里按钮不可用，并说明去 TMD 窗口 |
| 工程 | 已绑定工程文件夹。未绑定：提示去绑定，**禁止**浏览器逐张下载 |
| 目录 | `序列帧/{影棚名}/` |
| 帧文件 | `{影棚名}.0001.png`（4 位补零） |
| 镜头表 | 同目录 `镜头表.txt`：名称、模版、分辨率、fps、帧数、秒数、是否透明、演员（盒名/卡牌集名）、布景场景名或「无」 |
| 画幅 | 与当前红框同一套宽高；每张都是红框内成品 |
| 贴图 | 按出图贴图档 **重烘焙**，禁止复用视口低 DPI |
| 帧率 | 可键入，缺省 24（24 / 25 / 30 快捷）；帧数 = `round(总时长 × fps)`，至少 1 帧 |
| 进度 | 工作锁：「正在写序列帧」+ `第 x / N 帧`；可取消（已写的帧保留，不删目录） |
| 打开目录 | 「打开序列帧文件夹」：已绑定则打开 `序列帧/`（没有就先建）；未绑定要提示 |

不做：自动拼 mp4、运动模糊、音频。

开合 / 转台 / 张数变化写进每一帧的绘制状态，**不得**写进贴图 cache key。

### 导出模型（当前帧）

影棚模版不够用时，把 **播放头这一帧** 交出去给 Maya，不要在工坊里做第二套动画曲线。

入口：场景 Tab **导出模型**。格式、目录约定、单位、轴向、贴图档、工作锁、未绑定 zip，全部与 [product-render.md](./product-render.md)「导出模型」相同，**调用同一套导出器**（禁止影棚再写一份网格拼接）。

与产品渲染的差别只有 **导哪一帧的几何**：

- 几何 = 当前播放头的演员（开合整体居中、展开/分批可见张数已烘焙）+ 冻结布景（仍去掉与演员重复的件）
- 目录 `导出模型/{影棚名}/`（不要写进 `序列帧/`）
- `场景说明.txt` 写 **渲染机** 当前帧（rest + 转台偏航），以及操作机摘要；主光若开了跟随，写跟随后的 yaw
- 不含轨迹、机身、锥体、红框、空槽占位
- 必填槽空时：仍可导出已有物件（布景/已填槽），但提示缺哪一槽；全部空则禁用

包装单盒页本期 **不**做导出模型。

## 数据与状态

见 [data-model.md](../data-model.md) `Studio`、`StudioActor`、`StudioBackdrop`、`viewCamera` / `lookThrough`。改动经 `appStore.patchProject()`，进 undo。会话另记当前选中槽 `slotId`（不必进工程文件）。

一个项目可有 **0～多个** 影棚。进入影棚页 **不要**自动建。

会话：当前 `studioId`、库还是编辑器（对标 `boxLibraryOpen`）。

工程文件夹写入 **`data/studios/{id}.json`**（与 `shots/`、`boxes/` 同级）。漏写会导致重开后库空。

卡牌纸厚与卡芯仍只在卡牌规格里调；影棚读蓝图同步副本。

## 验收标准

- [ ] 工作区有项目级「影棚」，与「产品渲染」并列；路由不是 `/project/stage`
- [ ] 进入先看到影棚预览块库；空库不自动创建并跳进编辑；点块才进棚；可返回库
- [ ] 新建必须先选模版；至少有开盒转台、盒转台、排列展开、分批亮相四个
- [ ] 开盒转台槽位拒绝简单方盒，并说明需要详细天地盒；详细天地盒可填入
- [ ] 盒转台可填简单或详细盒
- [ ] 排列 / 分批可填卡牌集；空槽显示占位；必填槽空时不能渲染镜头
- [ ] 布景可选无 / 纯色 / 引用已有产品场景；引用后布景物件冻结、点不中、不出现控制杆
- [ ] 第一次把某场景设为布景时，操作机和渲染机都复制该场景看穿机；之后转操作机不改渲染机、不改那个场景
- [ ] 右栏有场景 / 灯光 / 摄影机 / 模版图标 Tab；灯光（强度/方位/俯仰/颜色、补光、环境）和 FOV、透视/等距可调，与产品渲染同一套字段
- [ ] 操作机与渲染机分开：看穿操作机时序列仍用渲染机；视口标明看穿哪台；可贴合切换
- [ ] 看穿操作机时画出渲染机机身、锥体、转台轨迹；导出序列没有这些
- [ ] 转台模版有「主光跟随转台」；开则主光 yaw 跟渲染机偏航同步，关则灯钉世界；跟手、无工作锁
- [ ] 开盒时天+地整体包围盒中心留在槽位原点，不是地盒钉死、天盒往外冒；网格仍按合盖建
- [ ] 选中盒槽：详细天地盒有合上/打开滑条（盒转台保持该开合；开盒转台滑条是开场）
- [ ] 选中牌槽：站姿、从–到、牌组/错落/一字/扇形与产品渲染一致；排列/分批终态读演员 stack，模版 Tab 不再重复终态下拉
- [ ] 布景与演员同一只盒或同一个卡牌集时，布景里不画那一件（无双影）
- [ ] 引用的场景删除后，影棚标布景丢失，演员仍可预览
- [ ] 开盒 / 转台 / 展开秒数、圈数、每批张数可键入；拖播放条立刻看到开合、旋转、展开或分批，**没有**工作锁、**没有**重载印刷图
- [ ] 开盒只抬天盒（加整体居中补偿），网格按合盖建
- [ ] 排列展开从收拢到扇/一字，逐张薄片，头尾与产品渲染一致，不镜像反字
- [ ] 分批按牌序出现，未出现的不画；超过 48 张截断
- [ ] 视口有分辨率红框；导出序列没有红框和辅助线
- [ ] 出图贴图默认最高，不复用视口糊贴图
- [ ] 桌面客户端 + 已绑定工程：写入 `序列帧/影棚名/影棚名.0001.png` 与 `镜头表.txt`；进度 `第 x / N 帧`，可取消
- [ ] 浏览器里不能跑序列，并说明原因
- [ ] 未绑定工程不能假装打开序列帧文件夹
- [ ] 产品渲染页没有「渲染序列帧」；静帧导出行为不变
- [ ] 影棚不提供倒角、UV、自由控制杆；盒子仍走包装 `boxDraw` + `coverBase`
- [ ] 场景 Tab 可导出当前帧模型到 `导出模型/{影棚名}/`（与产品渲染同一套 FBX）；几何是播放头状态；不含轨迹/红框；说明文本写渲染机当前帧
- [ ] 页头矮，教学在问号；左右栏可拖宽；颜色用 ColorField

## 已知限制 / 不做

- 第一期只有上表四个模版；没有用户自定义模版编辑器
- 没有成片时间轴（多个影棚串联以后再做）
- 不导入 GLB/FBX；布景只有纯色 / 无 / 产品场景
- 不内置交付 mp4；预览小视频以后用已写出的 PNG 压，不另做渲染器
- 模型导出是 ASCII FBX 当前帧，不是带动画曲线的 FBX
- 影棚只有 **操作机 + 渲染机** 两台，不是任意多机位剪辑；轨迹只画转台圆/弧，不能当 Graph Editor 拖点
- 分批是整批出现，不是单卡飞入抛物线
- 卡牌集仍受产品渲染 48 张上限
- 演员钉在模版槽位（世界原点附近），不对齐任意桌腿——要对齐去改被引用的产品场景

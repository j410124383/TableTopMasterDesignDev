# 说明书

> 桌游创作的第三维度：规则书 / 说明书。  
> 产品已确认**要有这个维度**；页面内编辑器细节尚未拍板，未写的交互不要当已定规格实现。

## 用户故事

- 作为设计者，我希望在同一个桌游项目里写说明书，而不是只做卡牌。

## 范围（已确认）

- 工作室「桌游创作」下与 **卡牌/板件**、**包装盒** 并列
- 用途：规则说明、组件清单、回合流程等给玩家看的文稿与排版

## 界面与交互（待补充）

以下仅占位，**不是**验收清单：

- 多页文档、页尺寸（如 A4 / A5）
- 文案、插图（可引用项目媒体与卡牌缩略图）
- 导出 PDF

未写入本文件「验收标准」前，实现最多做维度入口与空状态，不擅自做完整排版器。

## 验收标准

- [ ] 工作区能进入「说明书」维度
- [ ] 空状态说明「说明书编辑即将提供」，不假装已有完整编辑器

（完整编辑与导出的验收项待产品补交互后再加。）

## 已知限制 / 不做

- 当前不实现 InDesign 级排版、目录自动生成、多语言对照
- 不把说明书内容塞进蓝图图层凑合代替

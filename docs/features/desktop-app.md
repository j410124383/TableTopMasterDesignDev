# 桌面客户端

> 工坊的日常用法是 **自己的窗口**，不是系统浏览器。浏览器打开 localhost 只保留给试用、局域网旁观。  
> 后面要做 Maya 式 **序列帧渲染**（见 [product-render.md](./product-render.md)），长时间出图、连写几百张 PNG，浏览器标签会被节流、休眠，不适合当宿主。

## 用户故事

- 作为设计者，我希望双击 TMD 就出现工坊窗口，不必再开 Chrome，也不必盯着黑窗口。
- 作为设计者，我希望以后能像 Maya 那样把产品镜头渲成 PNG 序列；客户端要先就位，序列帧才能可靠写到工程目录。

## 范围

**做（本期客户端）**：

- Windows 上双击进入 **TMD 窗口**（WebView2 包现有界面）
- 本机文件夹、房间、联机卡图缓存、市集/论坛 **仍走现有本地服务**（`/__fs/`、`/__rooms/`、`/__play/` 等），用内置 Node 当 sidecar，不重写编辑器、不换三维引擎
- 启动后 **不要再调用系统浏览器**；服务起来后只开自己的窗口
- 控制台对用户隐藏或缩到托盘级（开发机仍可看日志）

**后期（已确认，不跟本期一起做）**：

- Maya 式产品 **序列帧**（转台一圈 → `序列帧/` 下 `名称.0001.png`…），规格写在产品渲染文档
- Mac 原生 `.app` / 签名（仍须在 Mac 上编）
- 把 sidecar 换成纯 Rust、或 Electron

**不做**：

- 用客户端换掉 Canvas / WebGL（牌桌和产品视口还是现在这套，不会因为套了窗口就自动不卡）
- 完整 Maya（Graph Editor、骨骼、Arnold）
- 把联机改成必须经公网服务器

离线 zip（[offline-pack.md](./offline-pack.md)）仍可打：给别人试用、或暂时没有安装包时。日常主路径改为窗口。落地页可继续提供 zip；有安装包后再加「下载 Windows 应用」。

## 启动

Windows 主入口是 **`TMD.exe`**（WebView2 窗口，不是系统浏览器）：

1. 用包内 Node 起本地服务（端口仍 1420，局域网联机地址不变）
2. 打开 TMD 窗口，加载 `http://127.0.0.1:1420/`
3. **禁止** `start http://localhost:1420/` 再弹出浏览器
4. 关掉窗口 = 结束工坊（停掉本地服务）

开发机打包：`npm run desktop:exe` 在仓库根写出 `TMD.exe`。`npm run pack` 会把这份 exe 打进 Windows zip。`打开卡牌工坊.bat` 若旁边已有 `TMD.exe` 会直接启动它；`/console` 仍开日志。

本机没有 Rust 时不走 Tauri 交叉编；Windows 窗口用 WebView2 壳 + Node sidecar。Mac 窗口包仍不能在 Windows 上交叉编出来。

## 打开工程文件夹

「打开」选文件夹时：

- 用 **系统标准的选文件夹对话框**（Vista 式，和「打开文件」同一套外壳），**不要**旧的树状 FolderBrowserDialog（那种路径浏览器）
- 对话框默认停在 **TMD.exe 所在目录**（开发时即工坊根目录），不要从「我的文档」或上次不知哪层盘符起

## 验收标准

- [ ] Windows 上双击 **TMD.exe** 只出现 TMD 窗口，不再打开系统浏览器
- [ ] 窗口内可进工作室、打开已有工程、产品渲染出一张静帧 PNG（行为与现网页一致）
- [ ] 局域网联机地址仍可用（服务仍听 1420）
- [ ] 关掉窗口后面板服务停掉，1420 不空占
- [ ] 「打开」选文件夹是系统标准对话框，默认从 exe 所在目录起
- [ ] 现有 zip 启动方式可保留，但主文档/落地说明以窗口为准

## 已知限制

- 窗口里仍是网页引擎画卡和 3D；进房卡顿靠 [play-mode.md](./play-mode.md) 的准备界面，不靠换壳
- 序列帧渲染 **本期不做**，只要求宿主不再是浏览器
- 无苹果电脑时出不了 Mac `.app`

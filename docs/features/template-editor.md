# 蓝图编辑器（Template Editor）

> 属于桌游创作的 **卡牌 / 板件** 维度，见 [pieces.md](./pieces.md)。  
> `[反推]` 路由：`/project/template`。源码：`src/features/template/`。

## 用户故事

- 作为设计者，我希望在 mm 精度的画布上排版卡牌或板件的正反面，以便导出与打印尺寸一致。
- 作为设计者，我希望把图层属性绑定到数据列，以便批量生成不同实例。
- 作为设计者，我希望预览真实 DPI 下的渲染效果。

## 界面与交互

### 布局

`[反推]`

- **左侧**：蓝图库（BlueprintLibrary）— 切换/新建/复制/删除蓝图
- **中央**：CardCanvas（Konva）— 可缩放平移的件画布（卡牌或板件）
- **右侧**：图层面板 + 属性面板 + 文本样式栏（TextStyleBar）
- **顶栏**：正/背面切换、插入图层（LayerInsertBar）、视口工具

### 图层操作


| 操作    | 方式                                                |
| ----- | ------------------------------------------------- |
| 选中    | 点击图层                                              |
| 移动/缩放 | 拖拽 / 变换手柄                                         |
| 新建    | LayerInsertBar：text / image / rect / icon / group |
| 复制    | Ctrl+D 或右键                                        |
| 粘贴    | Ctrl+V                                            |
| 删除    | Delete / Backspace                                |
| 层级    | Ctrl+↑/↓ 调整顺序                                     |
| 锁定/隐藏 | 图层面板按钮                                            |
| 重命名   | F2                                                |




### 视口与辅助线

`[反推]` 快捷键（WorkspaceLayout 全局 + 模板页）：

- `Home` — 适应视图；`End` — 100% 居中
- Ctrl+B — 出血线；Ctrl+G — 网格
- 可切换：安全区、裁切线、剔除/显示出血（cropBleed）
- 吸附：角点、中心、网格、出血/安全/裁切边

**剔除/显示出血**是按裁切线**裁掉或露出像素**，不是把整张卡重新缩放铺满窗口：

- **显示出血**：成品四周露出出血，成品 mm 比例与位置不变
- **剔除出血**：沿裁切线裁掉出血，成品比例不变（卡面变小一圈，不是放大铺满）
- 切换时不触发「适合窗口」；Home / 双击空白才重算缩放



### 蓝图与数据集独立（硬规则）

蓝图数据**永远独立于卡牌集**，不被任何数据集控制。

- 蓝图页（库缩略图、规格预览、画布编辑、图层面板）只渲染图层自身的 `text` / `style` / `visible` / 图片引用
- **禁止**用某个 CardSet（包括「第一个」或「默认」集）的 `cards[].fields` 覆盖蓝图显示
- `layer.vars` 只声明卡牌集可用哪些列，以及蓝图上该属性的**默认值仍存在图层上**；绑变量后编辑的仍是图层默认值，不是某张卡的数据
- 卡牌集 / Deck / 打印 / 对战才注入对应卡的 `fields` 覆盖绑定属性
- 单向同步：蓝图 `vars` 变更可把列名写入挂接的卡牌集 `fieldKeys`；卡牌集改字段**永不回写**蓝图图层

### 变量绑定

- 右键图层属性 →「转为变量」→ 选择属性（text/fill/src/active 等）
- 绑定后：卡牌集出现对应列；蓝图编辑器仍显示并编辑图层默认值
- `vars.active` 仅在卡牌集渲染时按 bool 列控制显隐；蓝图页只看 `layer.visible`



### 正反面

- CardFlipStage 支持翻转预览
- frontLayers / backLayers 独立编辑，共享 blueprint 尺寸



### 预览 DPI

- 编辑器可调预览 DPI（1–1000），存 localStorage
- 影响 CardCanvas 与 CardThumb 渲染清晰度



### 图片/图标

- 拖入或选择文件 → ingest 到 project.assets
- 支持 stock icons、PSD 导入（ag-psd）
- icon 层支持 repeat 变量按行排列



## 数据与状态

- 持久化：`Project.blueprints[].frontLayers / backLayers`（见 [data-model.md](../data-model.md)）
- 会话：`editorStore` — blueprintId, face, selectedId, view, previewDpi, clipboard
- 修改经 `appStore.patchProject()`，触发 undo 栈与 autosave
- 蓝图渲染传入空 `fields`，且 `honorVisibleWhen=false`（不套用卡牌集的 active / visibleWhen）



## 验收标准

- [ ] 可创建/切换/删除蓝图（至少保留一个）
- [ ] 五种图层类型可插入、编辑、删除
- [ ] 正反面独立编辑，flip 预览正常
- [ ] 图层 vars 绑定后，Sets/Deck 页对应列生效
- [ ] 蓝图库 / 规格 / 编辑画布的文案、颜色、图片、显隐均来自图层自身，不随默认卡牌集第一张牌变化
- [ ] 在蓝图页改图层默认值（含已绑变量的属性）只改蓝图，不改卡牌集已有字段
- [ ] Ctrl+Z/Y 撤销重做；Ctrl+S 保存
- [ ] 网格/出血/安全区/吸附开关有效
- [ ] 剔除出血为裁切而非缩放：成品比例不变，出血被裁掉；再显示出血时成品不跟着放大/缩小
- [ ] 锁定图层不可拖拽编辑
- [ ] group 子图层相对坐标正确



## 已知限制 / 不做

`[反推]`

- 无多选、无对齐分布面板（仅吸附）
- 旋转支持有限（rotation 字段存在，UI 待确认完整度）
- 非成品宽高的任意无限画布不支持（卡牌与板件都用 `blueprint.size`）
- 板件厚度不在本画布挤出 3D，只在属性里编辑（见 pieces.md）

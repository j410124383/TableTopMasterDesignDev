# 包装盒

> 桌游创作的第二维度。流程对齐常见「包小盒」：先出方盒 → 调参数 → 贴图 UV → 产品渲染。  
> **入口逻辑与蓝图一致**：先看预览块，再点进编辑。

## 用户故事

- 作为设计者，我希望先看到项目里有哪些包装盒的预览，再点进某一个去改。
- 作为设计者，我希望先得到一个默认方盒子，再改长宽高，而不是从空白建模开始。
- 作为设计者，我希望给整个盒子贴 **一张** 图，再在尽量大的 UV 编辑器里像 Maya 那样把每一面的壳自己放置、缩放、旋转，并能输入数值、吸附、重置单壳。
- 作为设计者，我希望产品视口像 Blender 一样有中心坐标、地面网格、方向轴和灯光指示物。

## 范围

**做**：闭合六面体方盒（长方体）的结构参数、**整盒一张贴图**、每面独立 UV 壳、三维产品渲染。

**不做**：按面各贴一张图、异形盒、插舌/锁底刀版、自由多边形建模、复杂材质节点。

一个项目可有 **0～多个** 包装盒；与卡牌/板件蓝图相互独立。

## 界面与交互

### 库：预览块 → 再进入编辑

工作区点「包装盒」后，**先进入包装库**（对标蓝图库），不要直接丢进某一个盒子的编辑器。

- 每个盒子一张 **预览块**（三维或静帧缩略 + 名称、尺寸）
- 点击预览块 → 进入该盒的编辑（结构 / 贴图 / 渲染）
- 顶栏或库内：**新建方盒**
- 右键：重命名、复制、删除（可删到 0 个，回到空状态）
- 编辑器内提供 **返回库**（与蓝图「回库」同一心智）

空项目：库为空态 + 「新建方盒」，**不要**在进维度时偷偷自动建一个并跳进编辑。

编辑态建议三个步骤（顶栏步骤或子导航）：

1. **结构** — 盒子参数 + 三维视口
2. **贴图** — 一张贴图 + **次级 UV 编辑器**
3. **渲染** — 产品渲染

### 1. 结构：默认方盒

点「新建方盒」时创建一个方盒，默认：

**10 × 15 × 5 cm**（长 × 宽 × 高）= **100 × 150 × 50 mm**

- 内部存储与卡牌一致，用 **mm**
- 面板上可同时显示 cm

用户可调：

| 参数 | 说明 |
|------|------|
| 长 lengthMm | 默认 100 |
| 宽 widthMm | 默认 150 |
| 高 heightMm | 默认 50 |
| 名称 | 盒子名称 |

面的命名（UV 壳）：**上、下、前、后、左、右**。六面共用一张贴图，不按面换图。

> 天地盖、抽屉盒等盒型本期不做；先把方盒跑通。

#### 三维视口（结构 + 渲染共用气质）

对标 Blender 视口的可读性，不是要做成完整 DCC：

| 元素 | 说明 |
|------|------|
| 世界原点 | 场景中心有可见的原点 / 中心坐标 |
| 地面网格 | 画在盒子**底面所在水平面**（能判断落地），线要够亮，不能埋进盒子中心看不见 |
| 方向轴 | 原点处 RGB 的 XYZ；以 overlay 画出，**不被盒子挡住** |
| 灯光指示物 | 主光方向上的灯标；转动灯光参数时跟着动；同样不被盒子挡住 |

结构编辑页的三维视口要占满剩余工作区（不要被页面 `max-width` 收成一条细缝）。库缩略图可以没有辅助线。导出 PNG **不含**网格/轴/灯标。

实时预览可以是低质量；点「渲染」再出高质量静帧。

### 2. 贴图与 UV（一张图，每面自己摆 UV）

整盒只有 **一张漫反射贴图**（写入 `project.assets`，与媒体库共用）。**禁止**「每面一张图」。六面都从这张图上采样；差异只来自各面自己的 UV。

未导入贴图时，三维盒与 UV 编辑器显示中性色或棋盘，不报错。UV 壳仍可编辑。

贴图格式：**PNG / JPG / WebP / PSD**。覆盖同一素材 id 后，盒子预览与 UV 必须立刻换图。

#### UV 编辑器（次级界面）

**真全屏**次级面板：铺满工作区（`100%` 宽高），不是居中的 1400×920 卡片。顶栏只留标题 + 完成；**中央画布占满剩余空间**；工具与数值在右侧栏。

画布交互：

| 操作 | 说明 |
|------|------|
| 滚轮 | **只缩放视口**（放大贴图）。禁止改壳的 w/h/scale |
| 中键 / 空格拖 | 平移视口 |
| 拖壳内部 | 移动当前壳。位移按指针当前 UV 计算，壳在屏幕上跟着鼠标走；视口放大后只是 UV 步进更细，不能再把 zoom 乘进 scale |
| 拖角点 / 边 | 缩放壳（改 Scale，默认等比例）。角点/边的命中区要比画出来的小方块更大，点在柄外侧也能拖。按指针 UV 算，与视口缩放无关 |
| 旋转手柄 | 旋转 |
| 边吸附 | **可开关**，右侧栏勾选，默认开。开：边对边、角对角，可贴齐贴图边界与其它壳；关：自由拖，不出现对齐线 |

光标随操作变化（提示当前能干什么）：

| 状态 | 光标 |
|------|------|
| 空白画布 | 默认 |
| 悬停壳内部 | grab |
| 拖移 | grabbing |
| 悬停缩放柄 / 边 | 对应 resize（nwse / nesw / ew / ns） |
| 悬停旋转 | 旋转光标 |
| 吸附命中 | 可保持当前柄光标，壳贴齐时给对齐线 |

右侧栏按钮：

| 操作 | 说明 |
|------|------|
| 上一面 / 下一面 | 切换 UV 壳 |
| 旋转 −90° / +90° | 当前壳 |
| 翻转 U / V | 当前壳 |
| **重置当前壳** | 只把选中面恢复为盒坯默认 UV，其它面不动 |
| 按盒坯重排全部 | 六面都恢复默认展开 |

右侧栏数值（与蓝图图层栏同一交互，可键入）：

| 字段 | 说明 |
|------|------|
| U / V | 壳中心（0–1） |
| W / H | 壳尺寸（未乘 scale） |
| Scale X / Scale Y | Unity 式缩放，默认 1；等比例开启时改一侧同步另一侧 |
| 等比例 | 开关，默认开 |
| 边吸附 | 开关，默认开；只影响画布拖拽 |
| 旋转 ° | |

屏幕上的壳 = 尺寸 × scale。旧数据无 scale 时视为 1。

### 3. 产品渲染

独立于结构编辑的渲染视口（同样有原点、地面网格、轴向、灯光指示物）：

| 可控项 | 说明 |
|--------|------|
| 盒子位置 / 旋转 | 场景中的物体变换；提供 **立着 / 躺着 / 侧躺** 预设，及 X/Y/Z 角度（数值栏可键入） |
| 摄像机 | 轨道旋转、距离、FOV |
| 灯光 | 主光方向（Yaw/Pitch）、强度、**ColorField 选色**；环境光、补光滑条；视口内灯光指示物同步 |
| 环境 | 背景色用 **ColorField**（见 [ui-consistency.md](./ui-consistency.md)） |
| 剔除背景 | 开关。开：不画底面/背景，PNG 背景透明 |
| 剔除盒子以外 | 开关。开：按盒子在画面上的包围盒裁掉四周，只留盒子 |
| 渲染 | 输出静帧（PNG）；分辨率可选（如 1920×1080、2048²） |

**导出路径**：写入**当前项目文件夹**下的子目录 **`渲染图/`**。文件名带盒子名与时间戳。未绑定本机文件夹时改为浏览器下载，并提示去绑定工程路径。

## 验收标准

- [ ] 工作区有「包装盒」维度；进入后先看到预览块库，点击才进入编辑
- [ ] 空库不自动创建并跳进编辑；新建后出现预览块
- [ ] 新建盒子即为 100 × 150 × 50 mm（界面可显示 10 × 15 × 5 cm）的方盒
- [ ] 改长宽高后面实时变化
- [ ] 结构/渲染视口有原点、地面网格、方向轴、灯光指示物（网格在盒底，轴/灯标不被盒子挡住；导出 PNG 不含）
- [ ] 整盒只能导入一张贴图，不能按面各贴一张
- [ ] UV 编辑器铺满工作区；滚轮只缩放视口；拖壳倍率不随视口缩放错乱；按钮与数值在右侧栏
- [ ] 缩放默认等比例；可解开 Scale X/Y（Unity 式）
- [ ] 可输入 U/V/W/H/Scale/旋转；可重置**当前**壳或重排全部
- [ ] UV 壳边吸附默认可关；操作时分光标
- [ ] 三维点面与 UV 选中同步
- [ ] 渲染页可调盒子位姿、摄像机、灯光并输出 PNG
- [ ] 可开关「剔除背景」和「剔除盒子以外」
- [ ] 有本机工程路径时，渲染图写到 `渲染图/`
- [ ] 覆盖贴图素材后预览更新
- [ ] 盒子数据保存在项目内，随项目保存/导出

## 已知限制 / 不做

- 不做每面独立贴图 / 多材质槽
- 不做任意拓扑的 UV（壳始终是矩形，对应盒子的六个平面）
- 不做刀版展开 PDF（可后期）
- 不做烫金/局部 UV 工艺层
- 不做物理正确全局光照；产品渲染以好看、可控为准
- 三维引擎选型实现时再定，不写死在产品规格里
- 视口对标 Blender 的**可读辅助**（网格/轴/灯标），不做完整建模工具

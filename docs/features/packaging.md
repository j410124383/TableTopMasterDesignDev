# 包装盒

> 桌游创作的第二维度。流程对齐常见「包小盒」：先出方盒 → 调参数 → 贴图 UV → 产品渲染。  
> **入口逻辑与蓝图一致**：先看预览块，再点进编辑。

## 用户故事

- 作为设计者，我希望先看到项目里有哪些包装盒的预览，再点进某一个去改。
- 作为设计者，我希望先得到一个默认方盒子，再改长宽高，而不是从空白建模开始。
- 作为设计者，我希望给整个盒子贴 **一张** 图，铺法能像桌面壁纸一样选原始尺寸 / 撑满 / 平铺，再在尽量大的 UV 编辑器里像 Maya 那样把每一面的壳自己放置、缩放、旋转，并能输入数值、吸附、重置单壳。
- 作为设计者，我希望产品视口像 Blender 一样有中心坐标、地面网格、方向轴和灯光指示物；渲染时可给棱边加倒角，盒子看起来更真实。
- 作为设计者，我希望能切 **简单方盒 / 详细天地盖**；详细时天、地可调底色、金属度、反光度，外壁烫金/UV 遮罩。
- 作为设计者，我希望三维里看到的就是帽盖式天地盒，并能在预览里打开/合上校对。
- 作为设计者，我希望打开天地盒时内壁不是外壁印刷图翻进来，内壁可以单独贴图和 UV，没有内图时就用底色。
- 作为设计者，我希望天盒开口那一圈能挖半圆抠手，方便玩家掀开帽盖；上下一对、左右一对可分别勾选，半径可调。

## 范围

**做**：

- **简单模式**：现在的闭合六面体方盒、整盒一张漫反射、每面 UV 壳、倒角、产品渲染
- **详细模式（天地盖）**：帽盖式套盒，同一只包装拆成 **天盒 + 地盒**；每件 **外壁 / 内壁** 各可一张印刷图、各一套 UV（内壁可空，空则底色）。预览可开合
- **天盒口沿半圆缺口**（详细模式）：开口那一圈四壁居中可挖半圆抠手；上下开口 / 左右开口可同时勾选；半径可调。地盒不挖。产品渲染 / 影棚跟包装网格，不另做一套缺口
- 整盒材质：底色、金属度、反光度（粗糙度）
- 工艺遮罩口：烫金、UV（局部光油）。跟 **外壁** 印刷 UV。用户上传 **黑白图**，白色为效果区

**不做**：抽屉盒、插舌/锁底刀版、异形盒、自由多边形建模、完整 PBR 贴图集（法线/粗糙度贴图）、按面各贴一张漫反射、复杂材质节点图。

一个项目可有 **0～多个** 包装盒；与卡牌蓝图、板件相互独立。产品渲染里一只盒仍是 **一件物件**（详细模式内部是天+地两块网格，一个控制杆）。

## 界面与交互

### 库：预览块 → 再进入编辑

工作区点「包装盒」后，**先进入包装库**（对标蓝图库），不要直接丢进某一个盒子的编辑器。

- 每个盒子一张 **预览块**（三维或静帧缩略 + 名称、尺寸）
- 点击预览块 → 进入该盒的编辑（结构 / 贴图 / 渲染）
- 顶栏或库内：**新建方盒**
- 右键：重命名、复制、删除（可删到 0 个，回到空状态）
- 编辑器内提供 **返回库**（与蓝图「回库」同一心智）

空项目：库为空态 + 「新建方盒」，**不要**在进维度时偷偷自动建一个并跳进编辑。

编辑态建议三个步骤（顶栏步骤或子导航）：

1. **结构** — 简单/详细、尺寸、材质底色；三维视口
2. **贴图** — 印刷图 + UV；详细模式分天盒/地盒；工艺遮罩口
3. **渲染** — 产品渲染（吃结构与贴图，不再另调倒角以外的盒型）

### 1. 结构：模式 + 尺寸

点「新建方盒」时仍是 **简单模式** 方盒，默认：

**10 × 15 × 5 cm**（长 × 宽 × 高）= **100 × 150 × 50 mm**

- 内部存储与卡牌一致，用 **mm**
- 面板上可同时显示 cm

结构页顶部：**模式** 二选一（立刻改网格，不另开工程）：

| 模式 | `mode` | 外观 |
|------|--------|------|
| **简单**（缺省） | `simple` | 现在这样：一只实心六面方盒 |
| **详细（天地盖）** | `lidBase` | 帽盖式套盒：地口朝上、天口朝下，天从外套住地 |

#### 天地盒是什么

包装里的 **天地盒 / 天地盖** 是两件套的帽盖纸盒（硬盒常用）：

| 件 | 结构 | 口朝哪 | 合盖时怎么待 |
|----|------|--------|----------------|
| **地盒** | 底板 + 四壁，开口那面没有整板 | 口朝套合轴的正方向（缺省朝上） | 在轴的负侧 |
| **天盒** | 顶板 + 四壁，开口那面没有整板 | 口朝套合轴的负方向（缺省朝下） | 在轴的正侧，从外套住地盒 |

合盖侧面必须能看出 **天的四壁叠在地的四壁外面**（套住），不是天坐在地的口沿上当锅盖，也不是两只口都朝上的托盘叠放。

套合轴向（详细模式，结构页三选一，立刻改口朝向）：

| 模式 | `sleeve` | 地口 | 天口 | 打开（天盒平移，不翻转） |
|------|----------|------|------|--------------------------|
| **上下**（缺省） | `upDown` | 上 +Y | 下 −Y | 天沿 +Y 抬起 |
| **前后** | `frontBack` | 前 +Z | 后 −Z | 天沿 +Z 朝前拉开 |
| **左右** | `leftRight` | 右 +X | 左 −X | 天沿 +X 朝右拉开 |

两口始终相对（对着套），只是换哪根轴。用户说的「地口朝前、天口朝后」就是 **前后**。禁止只做上下一种还靠整盒旋转冒充（整盒位姿是另外的立着/躺着）。

`lidHeightMm` / `baseHeightMm` 是沿 **套合轴** 的件深。闭合后该轴上的外尺寸：上下用 `heightMm`，前后用 `widthMm`（宽=Z），左右用 `lengthMm`（长=X）。

尺寸关系（壁厚按外尺寸往里扣；「外径」指垂直于套合轴的那一圈）：

- 上下套：地外径 = `lengthMm` × `widthMm`（X×Z）
- 前后套：地外径 = `lengthMm` × `heightMm`（X×Y）
- 左右套：地外径 = `widthMm` × `heightMm`（Z×Y）
- 地盒开口内径 = 外径 − 2×`wallMm`
- **天盒内径** = 地盒外径 + 2×`lidFitMm`
- **天盒外径** = 天盒内径 + 2×`wallMm`

禁止只把天盒外径做成「地盒外径 + 2×间隙」——那样扣掉壁厚后天盒内口比地盒还小，套不进去，口就开小了。

合盖竖直方向（上下套）：地盒底在地面；天盒顶面高度 = `heightMm`；天盒下沿必须低于地盒上沿（套住一截），不是天、地对口相碰。前后/左右套同理：天在轴正侧、地在轴负侧，合盖时套住一截。

三维上开口那一面是 **空洞**，只能看到口沿那一圈壁厚；禁止用一整块板把口封死。UV 仍可留该面壳给口沿贴图，但不能在网格上盖住开口。

用户可调（简单）：

| 参数 | 说明 |
|------|------|
| 长 lengthMm | 默认 100 |
| 宽 widthMm | 默认 150 |
| 高 heightMm | 默认 50 |
| 名称 | 盒子名称 |

详细模式在长宽之外：

| 参数 | 说明 |
|------|------|
| 合盖总高 heightMm | 扣上后天盒顶面的高度，默认 50 |
| 天盒高 lidHeightMm | 天盒外壁高度，默认约总高 × 0.45 |
| 地盒高 baseHeightMm | 地盒外壁高度，默认约总高 × 0.9（天盒要能套住地盒上沿） |
| 壁厚 wallMm | 默认 1.5；天、地同壁厚。0 则退回实心块，看不出套盖 |
| 套盖轴向 sleeve | 上下 / 前后 / 左右，缺省上下 |
| 套盖间隙 lidFitMm | **天内壁相对地外壁** 的余量，默认 1。天盒外径还要再加 2×壁厚 |
| 上下开口 lidNotchUpDown | 勾选：天盒开口圈「上下」那一对壁的口沿居中挖半圆。缺省关 |
| 左右开口 lidNotchLeftRight | 勾选：天盒开口圈「左右」那一对壁的口沿居中挖半圆。缺省关 |
| 开口半径 lidNotchRadiusMm | 半圆半径，mm；滑条 + 可键入。缺省 **10**。两组都不勾时此值不挖口，仍保存 |

合盖时：地盒底面在地面；天盒扣合，顶面高度 = `heightMm`。产品渲染里移动/旋转这只包装盒时，天+地一起走（打开时天盒的抬起算在这件内部，控制杆仍是一只盒）。

#### 天盒口沿半圆缺口

只在 **详细（天地盖）** 的结构页出现（套盖间隙下面）。简单方盒没有开口圈，不提供。

天盒开口那一圈有四壁。在勾选的那一对壁上，于 **口沿居中** 挖一个半圆，从开口边往封闭面挖进去（半径方向沿该壁、离开口沿），贯穿该壁壁厚（外壁到内壁同一缺口）。合盖时从缺口能看到地盒外壁，手指可以抠住天盒往套合轴正方向拉开。

两组是独立勾选，不是单选：

| 勾选 | 挖哪两壁 |
|------|----------|
| **只勾左右开口** | 开口圈上的左、右壁（没有左/右壁时：前、后壁） |
| **只勾上下开口** | 开口圈上的上、下壁（没有上/下壁时：前、后壁） |
| **两组都勾** | 开口圈四壁各一个半圆 |
| **都不勾** | 口沿平直，和现在一样 |

套合轴向决定开口圈是哪四壁，「上下 / 左右」始终指开口矩形上的两对边（优先世界轴：左右先认 ±X，没有则认 ±Z；上下先认 ±Y，没有则认 ±Z）：

| 套合 | 天口 | 开口圈四壁 | 上下开口挖 | 左右开口挖 |
|------|------|------------|------------|------------|
| **上下**（缺省） | 下 | 前、后、左、右 | 前 + 后 | 左 + 右 |
| **前后** | 后 | 上、下、左、右 | 上 + 下 | 左 + 右 |
| **左右** | 左 | 上、下、前、后 | 上 + 下 | 前 + 后 |

半圆：直径贴在该壁的开口边上，圆心在口沿中点，弧在壁面上。缺口是 **壁面内的平面半圆**（24 段），贯穿壁厚是直棱柱，内外弧对齐。禁止用一只角当扇心把对角三角形切穿缺口（看起来会像瘪的/尖的「怪半圆」）。不是在顶板上开窗，也不是地盒挖口。口沿厚度面跟着半圆弧走，缺口两侧仍有直段口沿。

半径夹紧：≥ 0；不超过该壁开口跨度的一半减去一丁点（别挖到墙角）；不超过天盒件深的约 90%（别把封闭面挖穿）。夹完仍小于约 0.5mm 则该壁不挖。改勾选或半径只改天盒网格，立刻看见；**不要**重载印刷图、**不要**工作锁、**不要**重建地盒。UV 壳仍是矩形，只是网格上少一块，采样还走该面壳。

产品渲染、影棚里的这只盒跟包装页同一套 `packagingPartMeshes`，不另做缺口、不另出控件。

#### 开合预览

详细模式在结构 / 贴图 / 渲染的三维视口提供 **合上 / 打开** + 0–1 滑条。打开方向跟当前 `sleeve`：只把天盒沿套合轴正方向平移，**不翻转**，地盒不动。行程默认约该件深 + 10mm，要能看见地盒口和天盒内壁。

| 状态 | `lidOpen` | 动作 |
|------|-----------|------|
| **合上** | `0`（缺省） | 按套合轴扣合 |
| **打开** | `1` | 天盒沿轴拉开 |

用来校对：两口朝向、天是否套得住地、两套贴图。不是铰链，也不把天盒翻成另一只碗。

滑条必须跟手、不能拖一下卡一下：

- **按住拖**：视口立刻跟手预览，**不要**每动一格就 `patchProject`、不要重载印刷图
- **松开**：这才写入 `lidOpen`（可用 mergeKey 合并）
- **点击滑条某点**、点「合上 / 打开」：立刻到位并写入
- 改 `lidOpen` 只动天盒位移，禁止重烘焙贴图、禁止重建地盒网格

库缩略图用合盖。产品渲染场景实例可覆盖 `item.lidOpen`（选中后合上/打开）；未写则跟随包装盒。简单模式没有开合。

从简单切到详细：把当前那张印刷图和六面 UV **复制**给天盒、地盒当起点（同一套图先都能用），用户再分别换成两张印件。从详细切回简单：保留天盒那套图和 UV 作为整盒贴图。

面的命名（每套 UV 壳）：**上、下、前、后、左、右**。简单模式六面采同一张印刷图；详细模式天盒六面采天盒图、地盒六面采地盒图。**禁止**按面各贴一张漫反射。

#### 材质（整盒共用，天/地一起）

结构页或贴图页一组即可，不要拆成两套材质：

| 参数 | 说明 |
|------|------|
| **底色** `baseColor` | ColorField，缺省白 `#ffffff`。没有印刷（或贴图透明）处显示底色；有印刷处 **贴图盖住底色**，不与底色相乘。底色不是油墨乘数 |
| **金属度** `metallic` | 0–1，缺省 0。滑条 + 可键入 |
| **反光度** | 界面用反光度 0–1（越亮越镜面）。存储为 `roughness`（粗糙度 = 1 − 反光度），缺省粗糙度 0.55 |

视口与出图都要看得出金属/反光变化（近似即可，不接 HDR 环境贴图）。倒角 `bevelMm` 仍绑定这只盒，简单/详细都吃。

#### 三维视口（结构 + 渲染共用气质）

对标 Blender 视口的可读性，不是要做成完整 DCC：

| 元素 | 说明 |
|------|------|
| 世界原点 | 场景中心有可见的原点 / 中心坐标 |
| 地面网格 | 画在盒子**底面所在水平面**（能判断落地），线要够亮，不能埋进盒子中心看不见 |
| 方向轴 | 原点处 RGB 的 XYZ；以 overlay 画出，**不被盒子挡住** |
| **指向性小坐标** | 视口角落（对标 Blender 右上/角标）：随镜头转的 RGB 轴，轴端写清 **右 / 左 / 上 / 下 / 前 / 后**（+X 右、−X 左、+Y 上、−Y 下、+Z 前、−Z 后）。库缩略图可没有 |
| 灯光指示物 | 主光方向上的灯标；转动灯光参数时跟着动；同样不被盒子挡住 |

库缩略图可以没有辅助线。导出 PNG **不含**网格/轴/灯标/角落小坐标。

改 **套合轴向、尺寸、壁厚、天盒口沿缺口** 只同步改网格开口，UV 壳仍按世界面 **上/下/前/后/左/右** 采样，禁止旋转网格时把岛镜像或把 U/V 换轴。印刷图已在内存里就不要重载、不要工作锁。只有第一次读入或更换印刷图才出工作锁。

**底色 / 金属度 / 反光度** 立刻作用：无图处是底色，有图处贴图盖住底色。开合滑条、摄像机、灯光只改预览，不重建、不锁。

实时预览可以是低质量；点「渲染」再出高质量静帧。产品渲染页的卡牌 / 板件同样：**视口可糊，出图必须重烘焙高清贴图**（见 [product-render.md](./product-render.md) 出图贴图）。

### 2. 贴图与 UV

**简单模式**：整盒 **一张** 漫反射印刷图 + 一套六面 UV 壳。闭合实心，看不见内壁，不提供内贴图。

**详细模式**：天盒、地盒分开编。每件有 **外壁** 和 **内壁** 两套：

| 层 | 印刷图 | UV | 没图时 |
|----|--------|-----|--------|
| **外壁** | 一张（必能导入，可空） | 一套六面壳 | 底色或棋盘 |
| **内壁** | 另一张，可空 | **另一套**六面壳，禁止采样外壁 UV | **只用底色**，不要把外壁印刷图翻到里面 |

贴图步骤：先切 **天盒 / 地盒**，再切 **外 / 内**。一次只编当前那一套壳。内壁 UV 编辑器标题写清例如「UV 编辑器 · 天盒内」。铺法 `textureFit` 外、内各自一份。

禁止：内壁复用外壁 UV 壳去采同一张印件（打开盒子会看到外面的图反着贴在内壁上，假）。禁止按面各贴一张。

未导入内壁图时，打开天/地应看到内四壁和内底/内顶是 `baseColor`，UV 壳仍可先摆好再贴图。内壁默认展开按 **内板尺寸**（外尺寸扣壁厚），不要拿外壁壳镜像当内壁。开口那面没有内板，该面壳可留空或只给口沿，网格上仍不得封口。

贴图格式：**PNG / JPG / WebP / PSD**。覆盖同一素材 id 后，预览与 UV 立刻换图。

铺法（每套印刷图各自一份）：

| 模式 `textureFit` | 壁纸对标 | 行为 |
|-------------------|----------|------|
| **原始尺寸** `original` | 居中 | 按贴图自身宽高比放入 UV，不拉变形、不强制铺满；四周可露底（露出底色） |
| **撑满** `cover` | 填充 | **默认**。1:1 等比放大直到铺满 UV 方，多出裁掉，不把图拉扁 |
| **平铺** `tile` | 平铺 | 按贴图宽高比重复铺满 UV；可调 `textureTileScale`（默认 1） |

UV 编辑器里看到的底图与三维采样必须同一套铺法，以及同一套 **贴图旋转**（见下）。禁止按面各贴一张漫反射。

套合轴向只决定哪一面开口，**不把 UV 岛跟着网格转**。三维每个世界面仍采该面在编辑器里的壳（上/下/前/后/左/右），s 沿面宽、t 沿面高，与盒坯 `faceCorners` 一致。禁止先按上下口建模再轴置换（会把岛的 V 和世界面 V 对反）。

**地盒外壁默认展开和天盒不是同一张十字网。** 刀版习惯：天盒按顶面朝着用户画，地盒按 **底面朝着用户** 画。地盒 **外壁** 盒坯（新建、重置当前壳、按盒坯重排全部）相对天盒/简单方盒那张十字网：

1. **前、后对调**：`front` 壳放到天盒网里 `back` 的位置，`back` 壳放到天盒网里 `front` 的位置。左 / 右 / 上 / 下先保持天盒网的邻接。
2. **整网旋转 180°**：六个壳作为一组，绕 UV 中心 `(0.5, 0.5)` 转 180°。每个壳：`u' = 1−u`，`v' = 1−v`，`rotationDeg += 180`（尺寸、scale、翻转不变）。

三维仍按世界面采该面的壳。**禁止**再在采样时偷偷把每个面的 s/t 转 180°（编辑器里壳已经转过，再转会叠两次，三维和 UV 对不上）。地盒 **内壁**、天盒、简单方盒仍用原来的十字网，不前后对调、不整网转。已保存过的壳坐标不要在打开工程时自动重排；用户点重置 / 重排才换成新网。

#### 工艺遮罩（烫金 / UV）

印刷图旁边提供贴图口（简单模式一份外壁；详细模式天/地的 **外壁** 各一份。内壁不做烫金口，避免和内印搅在一起）：

| 口 | 字段 | 用户怎么用 |
|----|------|------------|
| **烫金** | `foilMaskAssetId` | 上传黑白（或灰阶）图。**白 = 烫金，黑 = 没有**。灰按亮度混合 |
| **UV**（局部光油） | `varnishMaskAssetId` | 同样黑白。**白 = 更亮、更滑的光油区** |

遮罩 **沿用该件外壁印刷图的 UV 壳、铺法和贴图旋转**（同一套 `textureFit` / `textureTileScale` / `textureRotationDeg` 烘焙进 UV 0–1），不另开 UV 编辑器、不另选铺法。外壁印件怎么摆壳、怎么撑满/平铺、怎么转图，烫金/UV 黑白版就怎么对位。禁止遮罩按原图像素直接贴（会和印刷错位，效果区发黑或跑偏）。

- 烫金颜色：ColorField，缺省金 `#d4af37`。白色遮罩处 **盖住底色和印刷**，显示该金色
- **烫金可调**（贴图页，滑条+可键入，立刻作用、不重载贴图）：

  | 参数 | 字段 | 缺省 | 说明 |
  |------|------|------|------|
  | 烫金金属度 | `foilMetallic` | **0.95** | 越高越像金属 |
  | 烫金反光度 | 界面；存 `foilRoughness` = 1 − 反光度 | **0.88**（粗糙度 0.12） | 越高越亮；磨砂金不要到 1 |
  | 烫金磨砂 | `foilGrain` | **0.55** | 颗粒强弱。0 = 平滑镜面金 |
  | 烫金磨砂样式 | `foilGrainStyle` | **cell** 方块 | **方块**：现有格子颗粒。**颗粒**：无格子的连续磨砂。可切换，立刻作用 |

- UV 光油：白色处印件颜色仍在。可调（滑条可超过旧的 0–1 上限，才能做出夸张清漆）：

  | 参数 | 字段 | 缺省 | 范围 | 说明 |
  |------|------|------|------|------|
  | UV 反光度 | 存 `varnishRoughness` = 1 − 反光度 | **0.98**（粗糙度 0.02） | 反光度 0–1，粗糙度可低到 **0.002** | 越接近 1 越像镜子 |
  | UV 清漆 | `varnishCoat` | **1.5** | **0–4** | 镜面清漆强度。侧面掠射必须能看到环境反光，不能只有正对灯的一粒高光 |

UV 光油按 **镜面清漆** 画：白色遮罩处用菲涅尔 + 反射环境（天光/主光倒影），盒子侧壁、口沿掠射角也要发亮。禁止把清漆贡献卡死在 1.2；`varnishCoat` 拉满时接近镜子。

- 没上传遮罩 = 全关。不是必填
- 遮罩不参与扣形；透明当黑
- 详细模式打开后看见的地/天 **内壁**：没贴内图就是底色，不会自动用外壁印刷图。外壁印刷只在外侧；要盒内也有图，切「内」再贴一张

不要做成第二套六面独立 UV，也不要按面各贴一张烫金。

#### UV 编辑器（次级界面）

**真全屏**次级面板：铺满工作区（`100%` 宽高），不是居中的 1400×920 卡片。顶栏只留标题 + 完成；详细模式标题写清当前是 **天盒外 / 天盒内 / 地盒外 / 地盒内**；**中央画布占满剩余空间**；工具与数值在右侧栏。一次只编辑当前这套六面壳。

已绑定印刷图时，画布 **必须画出这张图**（按该层铺法烘焙进 0–1，再按贴图旋转）。加载失败要写「贴图加载失败」，禁止静默棋盘让人以为没导入。这一层还没图时写「先导入印刷图」，不要和失败混成同一种空棋盘。切天盒/地盒时默认回到 **外**。

画布交互：

| 操作 | 说明 |
|------|------|
| 滚轮 | **只缩放视口**（放大贴图）。禁止改壳的 w/h/scale |
| 中键 / 空格拖 | 平移视口 |
| 拖壳内部 | 移动当前壳。位移按指针当前 UV 计算，壳在屏幕上跟着鼠标走；视口放大后只是 UV 步进更细，不能再把 zoom 乘进 scale |
| 拖角点 / 边 | 缩放壳（改 Scale，默认等比例）。角点/边的命中区要比画出来的小方块更大，点在柄外侧也能拖。按指针 UV 算，与视口缩放无关 |
| 旋转手柄 | 旋转 |
| 边吸附 | **可开关**，右侧栏勾选，默认开。开：边对边、角对角，可贴齐贴图边界与其它壳；关：自由拖，不出现对齐线 |

光标随操作变化（提示当前能干什么）：

| 状态 | 光标 |
|------|------|
| 空白画布 | 默认 |
| 悬停壳内部 | grab |
| 拖移 | grabbing |
| 悬停缩放柄 / 边 | 对应 resize（nwse / nesw / ew / ns） |
| 悬停旋转 | 旋转光标 |
| 吸附命中 | 可保持当前柄光标，壳贴齐时给对齐线 |

右侧栏按钮：

| 操作 | 说明 |
|------|------|
| 上一面 / 下一面 | 切换 UV 壳 |
| 旋转 −90° / +90° | 当前 **壳**（改该面 `rotationDeg`） |
| 翻转 U / V | 当前壳 |
| **贴图旋转 90°** | 当前这套印刷图在 UV 0–1 里 **顺时针 +90°**，点一次转一次，360° 回到 0。只转底图，**不移动六个壳**。画布底图和三维采样同一角度。不是当前壳的 ±90° |
| **重置当前壳** | 只把选中面恢复为盒坯默认 UV，其它面不动。地盒外壁走地盒网（前后对调 + 整网 180°） |
| 按盒坯重排全部 | 六面都恢复默认展开。地盒外壁走地盒网 |

右侧栏数值（与蓝图图层栏同一交互，可键入）：

| 字段 | 说明 |
|------|------|
| U / V | 壳中心（0–1） |
| W / H | 壳尺寸（未乘 scale） |
| Scale X / Scale Y | Unity 式缩放，默认 1；等比例开启时改一侧同步另一侧 |
| 等比例 | 开关，默认开 |
| 边吸附 | 开关，默认开；只影响画布拖拽 |
| 旋转 ° | |

屏幕上的壳 = 尺寸 × scale。旧数据无 scale 时视为 1。

**贴图旋转**（每套印刷图各自一份，`textureRotationDeg` / `innerTextureRotationDeg`）：0 / 90 / 180 / 270，缺省 0。在铺法烘焙进 UV 0–1 **之后**顺时针转整张底图，六个壳坐标不动。烫金 / UV 遮罩跟该件 **外壁** 同一角度。右侧栏按钮「贴图旋转 90°」每次 +90，转满一圈回 0。立刻作用，不重载文件、不出工作锁。简单模式写在盒子根上；详细模式外、内分开。旧数据无此字段视为 0。

### 3. 产品渲染

独立于结构编辑的渲染视口（同样有原点、地面网格、轴向、灯光指示物）：

| 可控项 | 说明 |
|--------|------|
| 盒子位置 / 旋转 | 场景中的物体变换；提供 **立着 / 躺着 / 侧躺** 预设，及 X/Y/Z 角度（数值栏可键入） |
| 摄像机 | 轨道旋转、**中键拖平移**（Unity；Alt+左键同样平移）、距离、FOV。视口画 Maya 式分辨率红框，框外半透明黑；导出不含红框。多机位/大纲以产品渲染页为准 |
| 灯光 | 主光方向（Yaw/Pitch）、强度、**ColorField 选色**；环境光、补光滑条；视口内灯光指示物同步 |
| 环境 | 背景色用 **ColorField**（见 [ui-consistency.md](./ui-consistency.md)） |
| 剔除背景 | 开关。开：不画底面/背景，PNG 背景透明 |
| 剔除盒子以外 | 开关。开：按盒子在画面上的包围盒裁掉四周，只留盒子 |
| **边缘倒角** | `bevelMm`（mm）。把方盒十二条棱做成圆角/倒角，让边缘 smooth、更像实物。0 = 尖棱（默认）；上限不超过最短边的 1/4。结构视口与**本盒**渲染视口都要看得见。倒角**绑定这只包装盒**；工作区「产品渲染」里的盒子直接用这个值，**产品渲染页不得再调倒角** |
| 渲染 | 输出静帧（PNG）。分辨率：**预选**（HD / FHD / QHD / 4K、方图、竖图）+ **自定义宽高**（大于 0）。预选与自定义列表见 [product-render.md](./product-render.md) |

**导出路径**：写入**当前项目文件夹**下的子目录 **`渲染图/`**。文件名带盒子名与时间戳。未绑定本机文件夹时改为浏览器下载，并提示去绑定工程路径。渲染页提供 **打开渲染文件夹**（已绑定则打开 `渲染图/`，没有就先建；未绑定要提示）。

**后期**：单盒转台 / 开盒镜头改走工作区 **影棚**（见 [studio.md](./studio.md)），不要在本页再做一套序列帧。影棚演员引用这只包装盒。

单盒出图仍走本页。把卡牌、板件、多个盒子摆进同一张产品图，用工作区 **产品渲染**（见 [product-render.md](./product-render.md)），视口/灯光/导出与本页同一套，后续合并入口。

## 验收标准

- [ ] 工作区有「包装盒」维度；进入后先看到预览块库，点击才进入编辑
- [ ] 空库不自动创建并跳进编辑；新建后出现预览块
- [ ] 新建盒子即为 100 × 150 × 50 mm（界面可显示 10 × 15 × 5 cm）的方盒
- [ ] 可切简单 / 详细（天地盖）；详细是帽盖式套盒，天内径大于地外径并套住地；产品渲染里仍是一件
- [ ] 套合轴向可切上下 / 前后 / 左右（地口与天口相对：上-下、前-后、右-左）
- [ ] 详细模式可勾选天盒 **上下开口 / 左右开口**（可同时开、可都不开）；开口是口沿居中的 **平面半圆**（直径在口沿、弧在壁面），贯穿壁厚；地盒不挖；合盖能从缺口看到地盒外壁；不是对角扇形切穿后的尖/瘪缺口
- [ ] 缺省套合上下：只勾上下开口 → 天盒前+后壁口沿半圆；只勾左右开口 → 左+右壁；两组都勾 → 四壁都有
- [ ] 改缺口勾选或半径立刻改天盒网格；不重载贴图、不出工作锁、不重建地盒
- [ ] 详细模式视口可 **合上 / 打开**；打开沿当前套合轴拉开天盒、不翻转
- [ ] 开合滑条拖动跟手且不卡（拖时不写工程、不重载贴图；松手才保存）；点击滑条某点立即到位
- [ ] 可调底色、金属度、反光度；无印刷图时整盒是底色
- [ ] 详细模式天、地各有外壁印刷图+UV，以及可选的内壁印刷图+独立 UV；无内图时内壁是底色，不得把外壁图翻进去
- [ ] 烫金 / UV 遮罩口：黑白图、白为效果、沿用该件 **外壁** 印刷 UV、铺法和贴图旋转
- [ ] 烫金 / UV 可调金属度、反光度、磨砂、清漆强度；清漆 0–4、反光粗糙度可低到 0.002；烫金磨砂可切方块/颗粒；缺省见上表；改数值立刻看见，不重载贴图
- [ ] UV 光油区侧面掠射能看到镜面/天光，不只正对光源才亮
- [ ] 已绑定的天/地印刷图在 UV 编辑器里能看见；加载失败有文字，不是空白棋盘；切天/地默认停在「外」
- [ ] 打开套盒后没贴内图的内壁是底色；外壁印刷只在外侧，不是加载失败
- [ ] 改长宽高后面实时变化
- [ ] 结构/渲染视口有原点、地面网格、方向轴、灯光指示物，以及角落指向性小坐标（前/后/左/右/上/下）；网格在盒底，轴/灯标不被盒子挡住；导出 PNG 不含
- [ ] 改底色立刻改无图处（内壁无内图马上是底色）；有印刷处贴图盖住底色，不把印件乘成底色
- [ ] 套合轴向只改开口网格；世界面 UV 朝向与 UV 编辑器一致，不镜像、不换轴
- [ ] 地盒外壁盒坯：前/后壳对调后再整网绕 UV 中心转 180°；重置/重排走这套；内壁与天盒仍用原十字网
- [ ] 地盒外壁不再在采样时隐式 s/t 转 180°；UV 编辑器里的壳朝向就是三维朝向
- [ ] UV 编辑器有「贴图旋转 90°」：点一次顺时针 90°，只转底图不移壳；画布与三维一致；外/内各自一份
- [ ] 工作锁只在载入/更换印刷图或出图时出现；转镜头、灯光、底色、开合、改轴向网格禁止出锁、禁止重载贴图
- [ ] 整盒（或详细模式下每一件的外或内）只能导入一张漫反射，不能按面各贴一张；可贴图铺法：原始尺寸 / 撑满 / 平铺
- [ ] 渲染页可调边缘倒角，棱看起来 smooth
- [ ] UV 编辑器铺满工作区；滚轮只缩放视口；拖壳倍率不随视口缩放错乱；按钮与数值在右侧栏
- [ ] 缩放默认等比例；可解开 Scale X/Y（Unity 式）
- [ ] 可输入 U/V/W/H/Scale/旋转；可重置**当前**壳或重排全部
- [ ] UV 壳边吸附默认可关；操作时分光标
- [ ] 三维点面与 UV 选中同步
- [ ] 渲染页可调盒子位姿、摄像机、灯光并输出 PNG
- [ ] 渲染页分辨率有多档预选和自定义宽高；中键拖或 Alt+左键平移镜头；视口分辨率红框、框外半透明黑；导出图没有红框和遮罩
- [ ] 可开关「剔除背景」和「剔除盒子以外」
- [ ] 有本机工程路径时，渲染图写到 `渲染图/`；可打开该文件夹
- [ ] 覆盖贴图素材后预览更新
- [ ] 盒子数据保存在项目内，随项目保存/导出

## 已知限制 / 不做

- 不做每面独立漫反射 / 六张印刷图
- 倒角只做方盒棱边圆滑，不做任意倒角建模 / 布尔
- 不做任意拓扑的 UV（壳始终是矩形，对应该件的六个平面）
- 不做刀版展开 PDF（可后期）
- 不做抽屉盒、插舌、锁底；口沿只做上述半圆抠手，不做异形刀版、不做地盒对位缺口
- 半圆缺口边缘是壁厚截面，不要求沿圆弧再倒角（`bevelMm` 仍只做方盒十二条棱）
- 工艺遮罩只有烫金 + UV 两口，且只跟外壁印刷 UV；内壁不做烫金口
- 内壁是第二套图+壳，不是按面各贴一张，也不是第三套完整 PBR
- 金属/反光是近似好看，不保证物理正确 GI / IBL
- 三维引擎选型实现时再定，不写死在产品规格里
- 打开只沿套合轴平移天盒，不做铰链、不做把天盒翻成另一只碗
- 视口对标 Blender 的**可读辅助**（网格/轴/灯标），不做完整建模工具

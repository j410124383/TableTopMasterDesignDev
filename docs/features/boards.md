# 板件

> 桌游创作里与 **卡牌**、**包装盒** **并列** 的维度。  
> 板件 **不是** 又一张走图层的蓝图。流程：上传一张图（如 `秘宝.png`）→ 按透明通道 **扣形** → 给 **厚度** → 产品渲染里就能拖这块板。

## 用户故事

- 作为设计者，我希望工作区里「板件」和「卡牌」「包装盒」各是一个 Tab，不要挤在卡牌下面。
- 作为设计者，我手头有 `秘宝.png`（透明底），希望扣出外形、挤出厚度，而不是再画一层蓝图。
- 作为设计者，我做好板件后，要在产品渲染的「板件」栏里立刻能找到并放进场景。

## 范围

**做**：板件库（预览块）→ 导入一张贴图 → alpha 抠形 → 板厚与平面尺寸 → 产品渲染用立体板。

**不做**：板件蓝图画布、正反图层、数据集/卡组、卡牌规格模版、刀版 PDF、按颜色抠图（无透明的 JPG 当矩形板）。

卡牌仍走 [pieces.md](./pieces.md)（规格 + 蓝图 + 数据集）。旧工程里 `Blueprint.kind === "board"` 的图层板件：**渲染栏仍能列出**（兼容），新建一律走本页贴图板件。

## 界面与交互

### 工作区 Tab

与包装盒同级，顺序：

1. **卡牌**
2. **板件**
3. **包装盒**
4. **说明书**

进入「板件」后是 **预览块网格 + 右侧属性栏**，与 [卡牌规格](./pieces.md) 同一套：点块只选中，**不要**跳进另一页再「返回库」。空库：空态 + 「新建板件」。

每个预览块：扣形俯视缩略 + 名称 + 最长边 mm × 板厚。点块 → 右侧改名称、贴图、板厚、最长边。右键：重命名、复制、删除。禁止再做全屏编辑页。

### 新建 / 编辑

点「新建板件」（导入一张图后出现块并选中）：

1. **导入贴图**（与媒体库同一套 `accept`，见 [ui-consistency.md](./ui-consistency.md)）。写入 `project.assets`，板件只记 `textureAssetId`。推荐 **PNG 透明底**。
2. 名称默认用文件名（`秘宝.png` →「秘宝」），可改。
3. 立刻按贴图 **alpha 扣形** 预览（透明处挖空）。无 alpha 的图：整张矩形，并提示换透明 PNG 才能扣外形。
4. 右侧可调：

| 参数 | 说明 |
|------|------|
| 板厚 `thicknessMm` | 默认 **2** mm，≥ 0 |
| 最长边 `longestMm` | 平面包络的最长边，默认 **40** mm。另一边按贴图像素比 |

禁止再套卡牌圆角矩形、禁止再进蓝图图层编辑器。覆盖同一素材后，预览与产品渲染里的这块板立刻换图并重扣。

### 产品渲染

左栏 **板件** Tab 列出本维度所有 `Project.boards`（缩略用扣形图）。拖入 / 点击加入场景，与盒、卡一样是实例，可重复放。

三维网格：

- 顶面：贴图（透明处镂空）
- 底面：同一张图（印刷翻面，左右不反字）
- 侧面：沿扣形轮廓挤出 `thicknessMm`；侧边用轮廓近处的不透明像素色，不要把整张图裹到侧壁
- 趴地：板面平行地面、正面朝上。不要用卡牌 `cornerRadiusMm` 圆角盒冒充扣形

大纲里板件与卡/盒并列。旧 `kind=board` 蓝图若仍出现在场景里，网格可暂按旧矩形挤出，但库里的「新建」不再生产这种蓝图。

## 数据与状态

见 [data-model.md](../data-model.md) `BoardPiece`。修改经 `appStore.patchProject()`，进 undo。

产品渲染 `ProductShotItem.kind === "board"` 的 `refId` 指向 `BoardPiece.id`。

工程文件夹必须把板件写进 **`data/boards/{id}.json`**（与盒子、场景同级），贴图走 `assets/`。禁止只把场景里的 `kind: board` 实例写进 shots、却不写 `Project.boards`——重开后大纲会变成「板件丢失」。贴图读不到时：预览与场景用正确板尺寸的丢失占位（标丢失），**不要**用扑克牌圆角薄片冒充。

## 验收标准

- [ ] 工作区 Tab：卡牌、板件、包装盒、说明书并列；板件不再藏在卡牌二级栏
- [ ] 板件页是预览块 + 右侧栏，点块不跳页；空库不自动创建；新建后出现块，产品渲染板件栏能找到
- [ ] 保存后再打开，板件与贴图还在；场景里找不到 `BoardPiece` 时大纲写「丢失」，网格不是扑克牌形状
- [ ] 导入 `秘宝.png`（透明底）后外形按 alpha 扣下，可调板厚与最长边
- [ ] 无透明图当矩形板，并提示；不打开蓝图编辑器
- [ ] 覆盖贴图后预览与渲染换图；删除板件后渲染栏不再列出
- [ ] 场景里板件为扣形挤出，透明镂空，不是圆角扑克牌形状

## 已知限制 / 不做

- 不做矢量描边重绘、不做法线贴图、不做双面各一张图（底面用同一张翻面）
- 不做板件拼版 / 刀版
- 不按背景色抠 JPG
- 不做板件数据集（同一秘宝在场景里放多件即可）

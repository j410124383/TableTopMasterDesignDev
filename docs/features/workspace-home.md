# 首页与工作区（Workspace & Home）

> `[反推]` 路由：`/`、`/app`、`/project/*`。源码：`src/features/home/`、`workspace/`、`landing/`、`settings/`。

## 用户故事

- 作为用户，我希望管理本地项目、从模板创建、打开文件夹或 zip。
- 作为用户，我希望在工作区内按**桌游创作**的几个维度工作：卡牌/板件、包装盒、说明书。
- 作为用户，我希望卡牌/板件里再进蓝图、数据集、卡组，并自动保存。
- 作为新用户，我希望有 starter 模板和 onboarding 引导。

### 工作室首页（/app）

`[反推]` HomePage 多 Tab（homeViewStore.mode）：

| Tab | 内容 |
|-----|------|
| 桌游创作 | 项目列表、搜索、创建/打开/导入（原「卡牌创作」/「项目」） |
| 对战 | RoomList + 邀请组件 |
| 市场 | MarketPage embedded |
| 论坛 | ForumPage embedded |
| 新闻 | NewsPage embedded |

文案：**卡牌创作 → 桌游创作**（含落地页特性卡片、onboarding「卡牌创作 → 案例」）。

**项目操作**：

- 新建：CreateProjectDialog — 选 starter、名称、可选本地文件夹
- 打开：列表点击、选文件夹、导入 project.json / zip
- 右键：编辑元数据、导出 json/zip、在资源管理器显示、重链文件夹、忘记、取消订阅、**复制为新工程**
- **复制为新工程**：若源工程已有本机文件夹，在目标路径 **拷贝整个文件夹** 再改项目名/id，禁止把内嵌贴图的整包 JSON 一次 POST（大会失败并留下空 `data/`）。中文路径与空格可用。目标若只有空 `data/` 残留，允许覆盖写入。
- 路径丢失检测（PATH_LOST、folderGone）
- 书架视图切换（homeViewStore.shelf）

**Starter 模板**（见 data-model）：empty, poker, sanguosha, mtg, pokemon, mahjong, uno, halligalli

### 工作区（/project）

`[反推]` WorkspaceLayout：

**侧栏导航**（产品已确认的维度）：

1. **卡牌 / 板件** — 其下：**卡牌规格**（预览块）→ 蓝图（预览块）→ 数据集、卡组。见 [pieces.md](./features/pieces.md)
2. **包装盒** — 先包装库预览块，再进结构 / 贴图 / 渲染，见 [packaging.md](./packaging.md)
3. **说明书** — 见 [rulebook.md](./rulebook.md)

项目级（各维度共用）：变量、媒体、舞台、**产品渲染**（先场景预览块，再点进内部编辑，见 [product-render.md](./product-render.md)）、打印、设置

`[反推]` 当前侧栏仍是扁平：模板、卡牌集、卡组、变量、媒体、舞台、打印、设置。

**顶栏**：

- 保存、撤销/重做、导出 zip/json、快捷键帮助（?）
- 项目名称、Brand、PrefsMenu

**行为**：

- 未打开项目 → 重定向 `/app`
- dirty 后 500ms debounce 自动 persist
- Ctrl+S 保存；Ctrl+Z/Y 撤销重做
- 切换路由时 editorStore 会话保持
- OnboardingDock 新手任务

### 变量页（/project/vars）

- 编辑 ProjectVariable 全局替换
- tag / replacement / kind(text|icon)
- 进入变量页时，**仍显示卡牌/板件二级栏**（卡牌规格 / 蓝图 / 卡牌集 / 卡组），点栏即可跳到对应页。变量本身仍是顶栏项目级入口，不要把人困在没有二级栏的空顶栏里。

### 媒体页（/project/media）

布局：**撑满工作区内容区**，不要居中窄栏（禁止 `max-width: 1100px` 一类把网格挤窄）。

顶栏：

- 筛选、上传
- **一键更新**：对库里每一个素材，按它已记录的工程路径（`assets/…` 或 `/__fs/file` 的磁盘路径）去磁盘再读该文件，**写回同一 `assetId`**，清缓存并刷新所有引用预览。不弹逐个选文件。找不到路径的（纯 data URL、文件已删）跳过，结束后提示成功/跳过数量。
- 「覆盖当前」仍保留：给**某一个** id 换一份新文件（可改路径）

筛选 Tab（与搜索叠用）：

| Tab | 内容 |
|-----|------|
| 全部 | 所有 `project.assets` |
| 未引用 | 蓝图图层、卡牌集字段、包装贴图、封面、字体、变量图标都没用到 |
| 已引用 | 至少被上面任一处用到 |

引用判定要扫：蓝图 image/icon 图层、卡牌集/Deck 字段、`boxes[].textureAssetId`、封面、字体、变量。

**点击素材** → 打开**次级面板**（与 UV 编辑器同一套「画布 + 右侧栏」心智）：

- 大图预览
- 详细信息：assetId、种类、像素尺寸（能读到时）、**磁盘/工程路径**（可复制）
- **重新链接**：选新文件覆盖该 id（同「覆盖当前」）
- 复制 id、删除

网格仍用图鉴 `Pager`。

- 同名再导入 = 覆盖，不是新建一份
- 必须刷新所有引用：蓝图图层、卡牌集/Deck 预览、包装盒贴图、封面、变量图标、对战牌面
- 清掉该 id 的图片缓存（Canvas / 缩略图 / 3D 贴图），禁止继续显示旧图

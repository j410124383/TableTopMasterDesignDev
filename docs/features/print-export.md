# 打印与导出（Print & Export）

> 路由：`/project/print`。源码：`src/features/print/`。

## 用户故事

- 作为设计者，我希望在 A4 等纸张上自动拼版多张卡，以便家用打印机输出。
- 作为设计者，我希望导出 PDF，或按页 / 按单卡导出 PNG、JPG。
- 作为设计者，我希望一次勾选多个卡牌集，并直观预览每一页再决定导出哪些。
- 作为设计者，我希望 TTS 贴图、单图、打印拼版各显示该模式用得到的参数，并能把常用参数存成本机预设快速切换。

## 界面与交互

整页三栏：**左栏设置 | 中间导出预览 | 右栏小图**。左栏与预览、预览与小图之间的分隔边框可拖拽改宽度，宽度记入本机（见 [ui-consistency.md](./ui-consistency.md) 分栏宽度）。禁止固定死、拖不动。

### 左栏两个 Tab

左栏顶部两个 Tab，互斥，记住本次会话当前 Tab：

| Tab | 内容 |
|-----|------|
| **卡牌集** | 选要导出哪些集 |
| **导出模式** | 模式、纸张/行列、效果、格式、预设、导出按钮 |

#### Tab「卡牌集」

表格，列为（顺序固定）：

| 列 | 内容 |
|----|------|
| 是否选择 | checkbox |
| 卡图集 | `CardSet.name` |
| 数量 | 该集 `Σ cards[].qty`（张数合计） |
| 蓝图 | 该集 `blueprintId` 对应蓝图名称；找不到则显示「（无蓝图）」 |

表头提供 **全选 / 全不选**。勾选变化后重置页码与页勾选。至少勾一张集才能导出；未勾时导出按钮禁用，并提示「请勾选卡牌集」。

勾选某集时同步 `editorStore.setId`（方便其它页对上当前集）。勾选集合写入会话，不进 `Project.print`。

#### Tab「导出模式」

设置写入 `Project.print`，修改 debounce merge（进 undo）。

##### 参数预设（本机，对标 PS 首选项）

**不写入项目文件**，存在本机（localStorage）。跨项目、关浏览器再开仍在。预设只存导出参数（`PrintSettings`），不含卡牌集勾选、不含页勾选。

- 下拉：本机已存预设；空则显示「未选择预设」
- **读取**：把选中预设套到当前 `Project.print`（预览立刻变）
- **存储**：已选中某预设则覆盖该条（需确认）；未选中则等同另存为
- **另存为**：弹名（默认「预设 n」），新建一条并选中
- **删除**：删本机该条，不改当前画面上的参数

名称可重复时仍按 id 区分。损坏/解析失败的存储忽略并当成空列表。

##### 导出模式（三选一）

| 值 | 界面名 | 产物 |
|----|--------|------|
| `print` | 打印拼版 | 按纸张自动排卡，可出 PDF / 光栅图 |
| `tts` | TTS 贴图 | 按列×行拼成贴图页（桌游模拟器用） |
| `single` | 单图导出 | **每张卡单独一张图**（不拼版） |

切换模式后页码归零，页勾选重置。

**按模式隐藏用不到的控件**（字段仍可留在数据里，只是不展示、导出时不参与该模式）：

| 控件 | 打印拼版 | TTS 贴图 | 单图导出 |
|------|----------|----------|----------|
| 纸张、方向、自定义宽高 | 显示 | **隐藏** | **隐藏** |
| 边距 mm | 显示 | **隐藏** | **隐藏** |
| 卡间距 mm | 显示 | **隐藏** | **隐藏** |
| 偏移 X/Y | 显示 | **隐藏** | **隐藏** |
| 切割线（开关/颜色/线长） | 显示 | **隐藏** | **隐藏** |
| TTS 列 / 行 | 隐藏 | 显示 | 隐藏 |
| 双面 | 显示 | 显示 | 显示（正、背各出一张） |
| DPI、文件名模板 | 显示 | 显示 | 显示 |
| 效果、格式、预设 | 显示 | 显示 | 显示 |
| 导出 PDF | 显示 | 隐藏 | 隐藏 |

TTS 纸张尺寸由「列 × 行 × 卡尺寸」算出，不让用户填纸张/边距。单图没有页边距与卡间距。

单图模式：每条卡记录导出 **一张**（不按 `qty` 复制多份）。打印 / TTS 仍按 `qty` 展开后再拼版。

##### 导出格式（可多选）

- 勾选 **PNG**、**JPG**，至少勾一项。两项都勾则同一次导出各出一套（同名不同扩展名）。
- JPG 显示质量 1–100（默认 90）。
- **导出** 按钮按勾选格式出光栅图。
- 仅打印拼版额外提供 **导出 PDF**（不受 PNG/JPG 勾选影响）。

##### 导出效果（预览与导出一致）

叠在每张卡的成品图上（拼版页上是每一格；单图是整张图）：

| 效果 | 交互 |
|------|------|
| 是否圆角 | 开关。开：按该卡蓝图 `cornerRadiusMm` **裁成透明**（棋盘格露出来），禁止用白色填圆角外 |
| 是否出血 | 开关。开：导出含出血区（量用蓝图 `bleedMm`；打印拼版排纸仍用下方「出血 mm」）；关：裁到裁切线 |
| 是否描边 | 开关。开：显示描边颜色（`ColorField`）、粗细 mm。描边贴在卡 **外轮廓** 上（圆角开时沿圆角） |
| 是否并列描边 | 开关。开：沿卡轮廓再画一条 **向内平行** 的框线（与外缘之间留空隙），看起来像一圈浮雕/金边内框。显示颜色（`ColorField`）、线宽 mm、内缩 mm（外缘到该线中心的距离）。圆角开时沿圆角。可与「是否描边」同时开：外轮廓描边 + 内侧并列线 |
| 是否水印 | 开关。开：文字（默认项目名，可改）、不透明度 0–100%、**类型**。水印叠在 **整张导出图** 上（拼版页是整页，单图是该卡） |

水印类型（开水印后出现）：

| 值 | 界面名 | 铺法 |
|----|--------|------|
| `single` | 单一 | 一张，居中，默认斜放约 −30°（与现在一致） |
| `tile` | 平铺 | 同一文字按斜放重复铺满整张导出图；间距随字号自动（约 2.5 倍字宽），本期不另做间距滑条 |

并列描边默认关；默认色 `#c9a227`、线宽 0.35mm、内缩 1.2mm。内缩不得小于线宽一半，也不得把框缩进到卡中心消失。

打印拼版另保留原有排版用 **出血 mm**（加在卡四周再算能放几张），与「是否出血」（图里看不看得到出血像素）不是同一控件。

### 预览（中栏 + 右栏）

#### 页缩略图（右栏）

独立右栏，竖向排列小图，条目再多只在右栏里竖滑，**不进预览窗、不在预览四周留空边**。

- **打印 / TTS**：每一张拼版页一张小图。
- **单图**：每一张待导出卡一张小图；双面开启时角标区分正/背。
- 小图按导出图真实宽高比；底板深色棋盘格。

每张小图带 checkbox。栏顶 **全选 / 全不选**。默认全选。

点击小图（非 checkbox）：该页/该卡成为当前大预览。分页条仍与小图选择同步。

#### 大预览（中栏）

工具条 + 预览窗。预览台 **外框必须直角**（不要 `border-radius` 裁切），好对照单卡导出「是否圆角」是不是真镂空。导出图铺满本窗格（contain）。棋盘格只出现在圆角镂空、透明像素、以及比例对不上时的信箱边。

放大后若超出，滚动从左上开始。

- 当前选中页/卡的完整预览（含效果）
- 圆角剔除处必须是透明（预览棋盘格 / PNG），不要填白。JPG、PDF 再铺白底
- 显示该页 `宽×高 mm` 与导出像素
- **缩放**：`−` / `+` / **适应**；百分比数字框可键入。**100% = 铺满当前预览窗**（contain）。适应 = 回到 100% 并按窗格重算，即使已经是 100% 也要立刻撑满。切换导出模式后同样回到 100% 铺满。Ctrl+滚轮在预览台上缩放。缩放只改变预览显示，不改变导出 DPI

### 导出动作

- **导出**：按勾选格式写出 PNG 和/或 JPG；范围 = 勾选的卡牌集 ∩ 勾选的页/单图。busy / progress / error。
- **导出 PDF**（仅打印拼版）：`exportPrintPdf()`，范围同样跟页勾选。
- 下载经 `downloadBytes()`；多文件时打包或逐个下载（实现选一种，进度里写清楚）。

## 拼版逻辑

- `buildPrintJobs()` — 按选中 sets 生成 jobs
- `flattenPrintPages()` — 双面时正背配对
- `layoutSheets.ts` — 计算纸上能放几张、分页
- TTS：`ttsCols` × `ttsRows`，卡之间无间距、无用户边距
- 单图：不走纸张网格，一卡一页（逻辑页 = 一张导出图）

## 数据与状态

- 项目内：`Project.print?: PrintSettings`（见 [data-model.md](../data-model.md)）
- 本机：导出预设列表；左栏宽度；预览清晰度
- 会话：卡牌集勾选、页/单图勾选、当前 Tab、预览缩放
- 默认：`DEFAULT_PRINT`
- 渲染 DPI：设置里的 `dpi`（导出）；预览可用较低 DPI

## 验收标准

- [ ] 左栏「卡牌集 / 导出模式」两个 Tab；卡牌集表列为 是否选择、卡图集、数量（Σqty）、蓝图名
- [ ] TTS 模式不出现纸张、方向、边距、卡间距、偏移、切割线；打印拼版出现这些
- [ ] 单图模式每张卡单独一图，不拼到纸上；不出现纸张/边距/卡间距
- [ ] PNG、JPG 可同时勾选，一次导出两套；只勾一项则只出该项；一项都不勾则不能导出
- [ ] 圆角 / 出血 / 描边（颜色+粗细）/ 并列描边（颜色+线宽+内缩）/ 水印 开关后，大预览与导出图一致
- [ ] 并列描边是卡内平行框线，不是把外轮廓描边再画一遍；圆角开时跟着圆角走
- [ ] 水印类型「单一」居中一张、「平铺」铺满整张导出图；预览与导出一致
- [ ] 圆角剔除处预览/PNG 为透明（棋盘格），不是白角；JPG/PDF 铺白底
- [ ] 左栏、预览、右栏小图三栏；栏间可拖宽度
- [ ] 右栏竖向小图；中栏大预览铺满，图四周不再垫空边
- [ ] 「适应」把图铺满预览窗（100%）；切换模式后同样铺满；缩放百分比可键入
- [ ] 中栏主预览台为直角方形，不给预览图加 CSS 圆角，以便看出单卡导出是否真圆角
- [ ] 可改预览清晰度（标准/高清/精细）；默认高清，TTS 大图预览不发糊；清晰度不改导出 DPI
- [ ] 本机可另存/读取/覆盖/删除参数预设；换项目、重开应用后预设还在；预设不带走卡牌集勾选
- [ ] 多卡牌集勾选后合并导出
- [ ] 打印拼版可导出 PDF，尺寸与 mm 设置一致
- [ ] 裁切线仅打印拼版且开启时出现在预览和 PDF/页图上
- [ ] duplex 正背配对正确；单图双面时正、背各一文件
- [ ] 文件名模板替换正确（含 {项目}{牌组}{序号}{面}）
- [ ] `Project.print` 关闭项目再打开仍保留；预设不写入 project.json

## 已知限制 / 不做

- 不含专业印刷 CMYK 分色、刀模 PDF/X-4
- TTS 为行列贴图，不是通用桌游箱规则
- 水印本期仅文字，不做图片水印
- 预设不云同步、不进工程目录

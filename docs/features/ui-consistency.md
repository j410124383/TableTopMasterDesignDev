# UI 统一性

> 全应用共用的控件与交互约定。新页面应复用已有组件，而不是另做一套。

## 颜色

**统一组件**：`ColorField`（`src/ui/ColorField.tsx`）

- 蓝图属性、文本样式、打印裁切线、**包装盒主光/背景**等凡「选颜色」处，都用 `ColorField`
- 交互：色块按钮 → 弹出色盘（HSV / RGB、Alpha、十六进制输入）
- **禁止**在新功能里单独用 `<input type="color">`，除非 spec 明确例外

## 数值

- 毫米 / 厘米：包装盒结构用 cm 输入、mm 存储（与蓝图 mm 一致）
- 滑条：灯光强度、环境光、补光等连续量优先 `type="range"` + 当前值文字
- **可输入数值栏**与蓝图图层属性栏同一套：标签 + `type="number"`，可直接键入；UV 壳的位置 / 尺寸 / Scale X/Y、包装渲染机位等一律用这套，禁止只靠拖拽没有数字
- **百分比**（预览缩放、不透明度、JPG 质量等）必须可键入数字调整，禁止只有 ± 按钮或只读「xx%」

## 图鉴分页（Pager）

凡**缩略图网格 / 图鉴**分页（卡牌集浏览、素材库、以及同类图鉴）必须用同一套 `Pager`：

- 页码按钮：`1 2 3 … n`（当前页附近连续，两端与省略号）
- **输入跳转**：数字框 + 回车 / 「跳转」，越界钳到 `1…总页数`
- 上一页 / 下一页
- 显示「第 x / n 页（共 m 项）」
- 仅一页时隐藏分页条

打印拼版预览等「按页翻图」的浏览条也遵循同一交互（可复用组件）。

## 文件导入

- 图片 / PSD：与媒体库、图层插入一致  
  `accept="image/*,.psd,image/vnd.adobe.photoshop"`
- PSD 需已绑定本机工程文件夹（存 `.psd` 引用，预览经 `/__fs/file` 解码）
- **覆盖当前**：对已有 `assetId` 再导入同名或点「覆盖 / 重新链接」，保持 id 不变、写新字节、刷新所有引用预览。禁止覆盖时另开一个新 id 让旧引用继续指向过期图
- **一键更新**：不选文件。按每个素材已经记下的工程/磁盘路径，从磁盘再读并写回同一 id（外链 PS 改完图后点一次即可）。纯内存 data URL、路径丢失的跳过并汇报

## 次级界面

- 包装盒 **UV 编辑器**、**素材详情**均为全屏次级面板。贴满工作区视口（不是居中小卡片）；画布占满剩余空间；工具与数值在**右侧栏**（与蓝图「画布 + 右侧属性」同一逻辑）
- **卡牌规格不是次级面板**：预览块与右侧属性同页，点块只切换选中。「我的 / 模版」两个 Tab。见 [pieces.md](./pieces.md)
- **板件同样不是次级面板**：预览块 + 右侧改贴图与厚度。见 [boards.md](./boards.md)
- 主界面提供入口按钮（「打开 UV 编辑器」），不在侧栏塞满 UV 画布

## 分栏宽度（可拖拽边框）

凡是「画布 / 视口 + 左右侧栏」的编辑页，**侧栏边框必须可拖拽改宽度**（对标蓝图左右 `pane-resizer` / `Splitter`）：

- 包装盒 **UV 编辑器**的右侧工具栏
- **产品渲染**左栏产品库、右栏属性
- **影棚**左栏演员/布景、右栏图标 TabGroup（场景 / 灯光 / 摄影机 / 模版 / 演员）
- **打印导出**左栏设置与预览之间
- 其它同类左右分栏（素材详情右侧栏等）

宽度记入本机（localStorage），刷新保留。禁止只靠 CSS 固定死、拖不动。

## 页头教学（问号）

库页、编辑页的 **page-head 要矮**：标题 + 主按钮即可。

教学/操作说明（怎么点预览块、怎么拖、控制杆、快捷键提示）放到标题旁的 **问号图标**，悬停或点击弹出（对标工作区顶栏「快捷键 ?」、蓝图编辑器按 `?` 看说明）。

禁止用大段 `muted` 副标题把视口顶下去。蓝图库、包装库、产品渲染库、影棚库与编辑页同一套。

## 工作锁（体验未就绪时）

只要当前画面 **还不是用户刚改完之后的最终结果**，并且人必须等质变完成（读印刷图、出图写 PNG、写盘），才盖 **工作锁**。

| 要求 | 说明 |
|------|------|
| **挡住操作** | 盖住正在等的那一块。`pointer-events` 全拦 |
| **说正在干什么** | 短标题，例如「正在载入印刷图」「正在导出模型」 |
| **说到什么时候** | 有步数显示 `3 / 8`；没有就不确定条，超过约 1 秒补「已用时 Ns」 |
| **虚化** | 底下半透明+模糊 |
| **别闪** | 短于约 80ms 不出锁；结束立刻拿掉 |
| **不要滥锁** | 摄像机移动、灯光、底色、开合预览、位姿、只改网格/UV、**影棚播放条与秒数旋钮、主光跟随、操作机/渲染机轨道** **禁止**出锁，也禁止为此重载贴图 |

实现用共用组件。转镜头走 `patchProject` 合并机位时，不得把 `lid`/`base` 引用变化当成贴图过期。

实现用共用组件，不要每个页各做一套遮罩。

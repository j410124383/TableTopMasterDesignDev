# UI 统一性

> 全应用共用的控件与交互约定。新页面应复用已有组件，而不是另做一套。

## 颜色

**统一组件**：`ColorField`（`src/ui/ColorField.tsx`）

- 蓝图属性、文本样式、打印裁切线、**包装盒主光/背景**等凡「选颜色」处，都用 `ColorField`
- 交互：色块按钮 → 弹出色盘（HSV / RGB、Alpha、十六进制输入）
- **禁止**在新功能里单独用 `<input type="color">`，除非 spec 明确例外

## 数值

- 毫米 / 厘米：包装盒结构用 cm 输入、mm 存储（与蓝图 mm 一致）
- 滑条：灯光强度、环境光、补光等连续量优先 `type="range"` + 当前值文字
- **可输入数值栏**与蓝图图层属性栏同一套：标签 + `type="number"`，可直接键入；UV 壳的位置 / 尺寸 / Scale X/Y、包装渲染机位等一律用这套，禁止只靠拖拽没有数字

## 图鉴分页（Pager）

凡**缩略图网格 / 图鉴**分页（卡牌集浏览、素材库、以及同类图鉴）必须用同一套 `Pager`：

- 页码按钮：`1 2 3 … n`（当前页附近连续，两端与省略号）
- **输入跳转**：数字框 + 回车 / 「跳转」，越界钳到 `1…总页数`
- 上一页 / 下一页
- 显示「第 x / n 页（共 m 项）」
- 仅一页时隐藏分页条

打印拼版预览等「按页翻图」的浏览条也遵循同一交互（可复用组件）。

## 文件导入

- 图片 / PSD：与媒体库、图层插入一致  
  `accept="image/*,.psd,image/vnd.adobe.photoshop"`
- PSD 需已绑定本机工程文件夹（存 `.psd` 引用，预览经 `/__fs/file` 解码）
- **覆盖当前**：对已有 `assetId` 再导入同名或点「覆盖 / 重新链接」，保持 id 不变、写新字节、刷新所有引用预览。禁止覆盖时另开一个新 id 让旧引用继续指向过期图
- **一键更新**：不选文件。按每个素材已经记下的工程/磁盘路径，从磁盘再读并写回同一 id（外链 PS 改完图后点一次即可）。纯内存 data URL、路径丢失的跳过并汇报

## 次级界面

- 包装盒 **UV 编辑器**、**素材详情**均为全屏次级面板。贴满工作区视口（不是居中小卡片）；画布占满剩余空间；工具与数值在**右侧栏**（与蓝图「画布 + 右侧属性」同一逻辑）
- 主界面提供入口按钮（「打开 UV 编辑器」），不在侧栏塞满 UV 画布

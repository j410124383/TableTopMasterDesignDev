# 数据集与卡组（Sets & Deck）

> 属于桌游创作的 **卡牌** 维度，见 [pieces.md](./pieces.md)。蓝图与数据集不出现在板件、包装盒、说明书里。  
> `[反推]` 路由：`/project/sets`（浏览）、`/project/deck`（表格）。源码：`src/features/sets/`、`src/features/deck/`。

## 用户故事

- 作为设计者，我希望浏览数据集里所有件的缩略图，快速预览正反面（卡牌或板件）。
- 作为设计者，我希望用表格编辑每条记录的字段和数量，并导入/导出 CSV。
- 作为设计者，我希望管理多个数据集，每个集绑定不同蓝图。
- 作为设计者，我希望像飞书一样做多个**视窗**，每个视窗记住列顺序、显隐和列宽，方便校对。

## 界面与交互

### Sets 页（卡牌集浏览）

- 选择当前卡牌集（与 editorStore.setId 同步）
- 正/背面切换
- 缩略图网格（CardThumb），点击可放大预览（CardPreview）
- 右键菜单：打开 Deck 编辑、复制集、删除集、复制卡、删除卡
- 至少保留一个卡牌集，否则不可删最后一个
- 「在 Deck 中编辑」跳转 `/project/deck` 并 focus 对应卡

**分页**（图鉴规则，见 [ui-consistency.md](./ui-consistency.md)）：

- 每页仍约 36 张
- 页码 `1 2 3 … n`，可输入跳到指定页
- 覆盖素材后，本页缩略图必须换成新图（同一 assetId，见素材覆盖）

### Deck 页（表格 + 视窗）

对标飞书多维表格的「视窗」：**数据只有一份**（`cards` + `fieldKeys`），视窗只改变怎么看。

#### 视窗条

- 表头上方：视窗 Tab（当前高亮）
- 新建视窗 / 复制当前视窗 / 重命名（双击 Tab 或菜单）/ 删除（至少留一个）
- 切换视窗立即套用该视窗的列顺序、隐藏、列宽
- `activeViewId` 随项目保存

#### 列

- 列类型：text / bool（勾选）/ image / number
- **拖拽列头**调整顺序（写入当前视窗 `columnOrder`，不改 `fieldKeys` 全集顺序）
- **隐藏 / 显示列**：列头菜单；隐藏列不出现在表里，数据仍在
- **拉伸列宽**：拖列头右缘，写入 `columnWidths`
- 列重命名、列类型切换仍作用在数据集本身（所有视窗看到新列名/类型）
- 图片列：选择文件 ingest；若覆盖已有素材 id，预览立即更新

#### 其它表格能力

- 搜索（全字段模糊）
- 按列排序（本期可作当前视窗临时排序，不强制写入视窗数据）
- 批量设置 qty
- 增删行、复制行
- 导入：CSV / XLSX（`importCardsFile`）
- 导出：CSV / XLSX（`exportCardsCsv` / `exportCardsXlsx`）
- 右侧/live 预览选中卡正反面

### 卡牌集与蓝图关系

- 每个 CardSet 绑定一个 `blueprintId`（引用关系，不拥有蓝图数据）
- 蓝图数据永远独立：卡牌集的 `fields` 只影响本集预览 / 导出 / 对战，**不**控制蓝图页显示
- `fieldKeys` 由蓝图图层 vars 自动同步；Deck 页可增额外列
- 新建卡牌集：`createCardSet()` 继承蓝图字段，并带一个名为「默认」的视窗
- 单向：蓝图 vars 变更 → 同步列名到挂接集；卡牌集改值永不回写蓝图
- 蓝图新增列名时：各视窗 `columnOrder` 末尾追加该列，默认可见

## 数据与状态

- `Project.sets[]`、`Project.blueprints[]`
- `Card`: `{ id, qty, fields: Record<string, string> }`
- `fieldTypes`、`views`、`activeViewId`：见 [data-model.md](../data-model.md)
- 会话：`editorStore.setId`、`face`

## 验收标准

- [ ] 多卡牌集切换、复制、删除（保留至少一个）
- [ ] Sets 页分页为 `1 2 3 … n` 且可输入跳转；缩略图预览正确反映 fields
- [ ] 覆盖某素材后，所有用到该 id 的卡面预览更新
- [ ] Deck 可建多个视窗、重命名、切换；列拖拽顺序 / 隐藏 / 列宽按视窗记住
- [ ] 视窗不改 cards 数据；删视窗不能删光
- [ ] Deck 页编辑 fields/qty 后预览即时更新
- [ ] bool 列显示勾选，image 列可上传
- [ ] CSV/XLSX 导入导出字段对齐
- [ ] 列重命名同步更新所有 card.fields 键
- [ ] 蓝图 vars 变更后 fieldKeys 自动同步，且各视窗能看到新列
- [ ] 在 Deck 改某张卡的字段后，蓝图编辑器显示不变

## 已知限制 / 不做

`[反推]`

- 无 Excel 级公式列
- 无数据库式 relational 字段
- Sets 与 Deck 实际编辑同一 `sets` 数据，仅 UI 不同
- 本期视窗不强制持久化筛选器 / 分组（列布局优先）

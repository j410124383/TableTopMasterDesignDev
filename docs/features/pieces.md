# 卡牌 / 板件

> 桌游创作的第一维度。蓝图、数据集、卡组只存在于此维度内。  
> 蓝图编辑细节见 [template-editor.md](./template-editor.md)；数据集见 [sets-and-deck.md](./sets-and-deck.md)。

## 用户故事

- 作为设计者，我希望在同一套工作流里做卡牌和板件：都有蓝图和数据集。
- 作为设计者，我希望卡牌保持平面（无厚度），板件可以设置厚度。

## 范围

卡牌与板件是**同一类「件」**，共用：

- **蓝图**：正反面图层、尺寸、出血、圆角、变量绑定
- **数据集**：挂接一张蓝图，表格填内容，批量生成实例
- **卡组**：数量与打印/试玩用的清单

二者的唯一硬差别：

| | 卡牌 | 板件 |
|--|------|------|
| `kind` | `card` | `board` |
| 厚度 | **无厚度**（不展示、不存储有效厚度，恒为 0） | **可设置厚度** `thicknessMm` |
| 编辑器 | 同一套蓝图画布 | 同一套蓝图画布 |

厚度用于后续立体预览、包装对照、生产说明；**不改变** 2D 蓝图排版与打印拼版（拼版仍按 `size` 宽高）。

## 界面与交互

### 工作区内的位置

打开项目后，桌游创作先选维度 **卡牌 / 板件**，其下才是：

- 蓝图（原「模板」）
- 数据集（原「卡牌集」）
- 卡组

项目级入口（变量、媒体、舞台、打印、设置）仍可用；打印主要服务本维度的件。

### 新建件

新建蓝图时选择类型：**卡牌** 或 **板件**。

- 默认尺寸仍用 `Project.meta.defaultSize`
- 选板件时，属性里出现「厚度」；选卡牌时不出现厚度控件
- 已有蓝图可改类型：改为卡牌则丢弃厚度；改为板件则厚度从 0 起编（或给一个小默认，如 2 mm）

### 厚度（仅板件）

- 单位 mm，≥ 0
- 默认建议 2 mm（可在实现时用项目默认）
- 0 表示极薄板，仍算板件（有厚度字段），与卡牌「无此字段」不同

## 数据与状态

见 [data-model.md](../data-model.md) `Blueprint.kind`、`Blueprint.thicknessMm`。

## 验收标准

- [ ] 工作区能进入「卡牌 / 板件」维度，其下可打开蓝图、数据集、卡组
- [ ] 新建可选卡牌或板件
- [ ] 卡牌属性中没有厚度；板件可输入厚度（mm）
- [ ] 卡牌与板件都走同一套蓝图图层与数据集绑定
- [ ] 改 kind 为卡牌后厚度不再参与显示与导出元数据

## 已知限制 / 不做

- 本期不做板件的 3D 斜视预览（厚度先当数值属性）
- 不做自由厚度剖面/倒角
- 卡牌不得通过「厚度 0」冒充板件；类型是 kind，不是厚度

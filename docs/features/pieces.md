# 卡牌

> 桌游创作里与 **板件**、**包装盒** **并列** 的维度。蓝图、数据集、卡组只存在于卡牌内。  
> 板件见 [boards.md](./boards.md)（贴图扣形 + 厚度，不走蓝图）。  
> 蓝图编辑细节见 [template-editor.md](./template-editor.md)；数据集见 [sets-and-deck.md](./sets-and-deck.md)。

## 用户故事

- 作为设计者，我希望用蓝图和数据集做卡牌，不要和板件挤在同一个 Tab。
- 作为设计者，我希望先定几种 **卡牌规格**（纸张物理参数），再让多张蓝图共用；同一规格可以竖放也可以横放。
- 作为设计者，我希望卡牌能设纸厚和卡芯（给产品渲染用）；2D 排版仍然按成品宽高。

## 范围

卡牌是带规格的「件」，包含：

- **卡牌规格**（`PieceSpec`，`kind: "card"`）：成品尺寸基准、出血、圆角、纸厚、卡芯。以 **预览块** 存放，多张蓝图共用
- **蓝图**：正反面图层、变量绑定；挂一条规格，并选定 **竖放 / 横放**
- **数据集**：挂接一张蓝图，表格填内容，批量生成实例
- **卡组**：数量与打印/试玩用的清单

板件已独立，见 [boards.md](./boards.md)。本维度 **不再新建** `kind: "board"` 的规格或蓝图。

厚度与卡芯用于 **产品渲染** 的立体外观（挤出、侧边颜色）；**不改变** 2D 蓝图排版与打印拼版（拼版仍按蓝图当前 `size` 宽高）。圆角 `cornerRadiusMm` 同时用于 2D 裁切外观与产品渲染网格。

## 界面与交互

### 工作区内的位置

打开项目后，桌游创作一级 Tab **卡牌** 与板件、包装盒并列，其下二级栏顺序固定：

1. **卡牌规格** — 预览块库 + **右侧栏**改参数（不进次级页）
2. **蓝图** — 先库预览块，再进图层编辑
3. **数据集**
4. **卡组**

规格在蓝图前面。蓝图与包装盒、产品场景：**先库预览块**。规格点块只选中并在右侧改，**不要**再开一层全屏编辑页。

项目级入口（变量、媒体、舞台、打印、设置）仍可用；打印主要服务本维度的件。

### 卡牌规格库（预览块 + 右栏）

进入「卡牌规格」是 **网格块 + 右侧属性栏**，对标蓝图「库 + 右侧」，不是包装 UV 那种全屏次级面板。禁止点块跳进另一页再「返回库」。

每个块展示：

- 按该规格竖放基准画出的圆角成品轮廓（可带出血线），不是某张蓝图的牌面图
- 名称；模版块加「模版」标记
- 短边×长边 mm、纸厚/板厚、卡芯（仅卡牌）、引用它的蓝图数量（模版未写入项目，引用为 0）

网格分两个 Tab（一次只显示一组，不要同屏两坨）：

1. **我的** — `Project.pieceSpecs`，可编辑
2. **模版** — 只读，代码内置，不进 `pieceSpecs`

默认停在 **我的**。模版 Tab 提供复制为自定义。本页 **不要**「新建板件规格」（板件走 [boards.md](./boards.md)）。

操作：

- 点块 → 选中，右栏显示该条。模版：全部控件只读，提供 **复制为自定义**。自定义：右栏直接改名称与物理参数
- **新建规格**：空白自定义（默认用 `Project.meta.defaultSize` 作竖放基准，出血 3、圆角 3、纸厚 0.32 / 白芯）
- 右键自定义：重命名、复制、删除（仍有蓝图引用时禁止删）。模版不能删、不能改
- 左右栏宽度可拖，见 [ui-consistency.md](./ui-consistency.md)

空项目：至少有一条自定义规格（建议用「扑克牌」模版复制出来的那条作默认），不要零规格。模版始终显示。

### 规格里有哪些参数

就是现在蓝图「规格页」里的物理项，从蓝图抽到规格上：

| 字段 | 说明 |
|------|------|
| 名称 | 如「标准牌」「小规格」 |
| 类型 | 仅卡牌（本页不再建板件规格） |
| 竖放基准宽×高 mm | **始终按竖放存**：宽 = 短边、高 = 长边。横放蓝图只是把这两边对调，不另存一套尺寸 |
| 出血 mm | |
| 圆角 mm | |
| 卡牌厚度 / 板厚 mm | |
| 卡芯 | 仅卡牌：白芯 / 黑芯 |

改规格 → 所有挂这条规格的蓝图立刻换物理尺寸（横放的仍是对调后的宽高）。**不改图层、不改名称、不改 id、不改卡牌集数据。**

### 蓝图怎么用规格

每张蓝图必须挂一条规格，并选定朝向：

| 朝向 | 蓝图实际 `size` |
|------|-----------------|
| **竖放** `portrait` | `{ w: spec.w, h: spec.h }` |
| **横放** `landscape` | `{ w: spec.h, h: spec.w }` |

例：一条规格竖放基准 63×88。

- 使徒、圣器、神契 → 同一规格 + 竖放 → 画布 63×88
- 石碑、灾祸 → 同一规格 + 横放 → 画布 88×63
- 回廊、命运、奖励 → 另一条规格（另一套宽高/出血/圆角/纸厚）

新建蓝图：默认挂 **当前项目里的默认规格**（最近用过的；没有则第一条），朝向默认竖放。用户可在蓝图块的规格入口改挂规格、改横竖。

蓝图库块上显示：规格名 · 竖放/横放 · 当前宽×高。

蓝图侧不再单独编辑宽高/出血/圆角/纸厚/卡芯。要改物理参数去规格库。某张牌要独特尺寸： **另存为新规格** 再只挂这一张，禁止在蓝图上偷偷改 mm 造成同规格分裂。

切换横竖 **只换画布宽高**，图层坐标不自动重排（避免把已排好的横版图层弄乱）。

### 新建件

新建蓝图即为 **卡牌**，必须挂卡牌规格（没有则先建一条）。不要在卡牌维度里再选「板件」。

已有 `kind: "board"` 的旧蓝图：不在本页新建；产品渲染兼容列出，完整板件工作流见 [boards.md](./boards.md)。

### 卡牌厚度与卡芯

- 纸厚单位 mm，> 0，默认 **0.32**（约一张扑克纸）
- **白芯**（默认）：产品渲染中卡牌 / 卡牌集的**侧边为白灰色**，不是把正面贴图裹到边上
- **黑芯**：侧边深灰
- 旧蓝图没有这两项时：纸厚按 0.32、卡芯按白芯，再打进规格

板厚不在本页调，见 [boards.md](./boards.md)。

## 打开旧工程（迁移，不准弄坏数据）

在 `normalizeProject()` 里做，**可重复跑**（已有 `pieceSpecs` 且蓝图都有合法 `specId` 则跳过）。

硬约束：

- 不改 `blueprint.id` / `name` / `frontLayers` / `backLayers`
- 不改 `sets` / `cards` / `assets` / 包装 / 场景
- 不改蓝图当前 `size.w/h` 的数值（横版仍是横的，竖版仍是竖的）
- 只 **新增** `pieceSpecs[]`，给蓝图补 `specId` + `orientation`

合并规则（物理指纹，与名字无关）：

1. 朝向：`size.w > size.h` → 横放，否则竖放（正方形算竖放）
2. 竖放基准：`{ w: min(w,h), h: max(w,h) }`
3. 指纹（四舍五入到 0.01 mm）：`kind | 基准w | 基准h | bleed | corner | thickness | core`
4. 同一指纹的蓝图共用 **一条** 规格
5. 规格名：组里只有一张蓝图用「{该蓝图名}规格」；多张用「规格 n（短×长）」——用户随后可改成「标准牌」等。禁止用游戏牌名硬编码
6. 默认规格：引用最多的那条；并列则第一条

这样「使徒/圣器/神契（竖）+ 石碑/灾祸（横）」只要成品矩形、出血、圆角、纸厚、卡芯一样，会自动并成一条规格；「回廊/命运/奖励」尺寸不同则自然是另一条。

## 数据与状态

见 [data-model.md](../data-model.md) `PieceSpec`、`Blueprint.specId` / `orientation`。改动经 `appStore.patchProject()`，进 undo。

渲染、打印、产品渲染继续读蓝图上的 `size` / `bleedMm` / `cornerRadiusMm` / `thicknessMm` / `core`（由规格 + 朝向同步上去的副本），不要满项目去查规格再算一遍才画得出。

## 验收标准

- [ ] 卡牌二级栏最前是「卡牌规格」：预览块 + 右侧栏；点块不进次级页
- [ ] 「我的 / 模版」两个 Tab，不同屏两坨；本页没有「新建板件规格」
- [ ] 内置模版（扑克/塔罗/三国杀/万智牌等）只读，可复制为自定义；自定义才能改 mm
- [ ] 规格含：竖放基准宽高、出血、圆角、纸厚、卡芯
- [ ] 蓝图必须挂规格，可选竖放/横放；横放宽高对调，图层不自动重排
- [ ] 改规格后所有引用蓝图的物理参数一起变；图层与卡牌集数据不变
- [ ] 新建蓝图默认挂默认规格 + 竖放，且为卡牌（不在此维度新建板件）
- [ ] 旧工程打开后按指纹合并规格，蓝图 id/名/图层/尺寸数值不变
- [ ] 仍有蓝图引用时不能删规格
- [ ] 产品渲染、打印仍用蓝图上的尺寸/圆角/纸厚（与规格同步后的值）

## 已知限制 / 不做

- 蓝图画布本身不做 3D 斜视；立体只在产品渲染里看
- 不做自由厚度剖面/卡牌倒角建模（卡牌圆角走 `cornerRadiusMm`）
- 卡芯本期只做白芯 / 黑芯，不做自定义侧边贴图或彩芯渐变
- 切换横竖不自动旋转/重排图层
- 规格库不做云同步、不进素材市场
- 内置模版尺寸是常用口径，不是某发行商授权数据；不保证每套实体印刷误差
